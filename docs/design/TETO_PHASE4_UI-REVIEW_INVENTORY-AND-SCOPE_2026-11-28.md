## 1. 調査方法と前提

| 項目 | 内容 |
|---|---|
| 対象コード | `main` = `0c755d02`（PR #926 マージ直後）。本番既定 `PROGRESSION_MODEL_PRODUCTION_DEFAULT = "shop"` |
| 確認方法 | ローカルの Vite DEV サーバーを `?progression=shop` / `?progression=legacy` で起動し、Playwright（Chromium）で画面を操作・撮影。撮影用スクリプトは作業用の一時ファイルで、リポジトリには追加していない |
| ビューポート | 390×844（HV 基準）。#884 確認のため PC 1440×900 を併用 |
| セーブ状態 | (a) 新規セーブ（評判 0、所持 3 種）、(b) e2e の `legacyStartupSave`（Pitz 731、マルゲリータ開発済み）を shop で開いた状態。中盤以降（評判の高い段階）の画面は撮影していない（§7 の残課題） |
| 調理工程の操作 | e2e の `gestures.ts`（生地・ソース・チーズ・バジル・焼き・カット）でマルゲリータの注文を 1 周 |
| モック | てっちゃん hero v4（Owner が本 PR の依頼時に提示した画像）。リポジトリ内に hero v4 の記述は見つからなかったため、本書の差分は提示画像を基準にする。モック画像の扱い（コミットするか）は §6 の論点 |
| 用語 | 「初見の分かりやすさ」= 説明なしで次に押すボタンと目的が分かるか。「ストア映え」= ストアのスクリーンショット 1 枚として切り出したときに、ゲームの内容と雰囲気が伝わるか |

撮影上の制約:

- DEV サーバーのため、Preview バッジや開発用の項目（設定の「開発用データ編集」）が表示される。本番では出ない項目は棚卸しから除いた。
- 自動操作のため、実機のタッチ感や動き（アニメーション）は評価していない。
