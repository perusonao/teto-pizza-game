# PIZZA GAME MVP Spec (Phase 1 Vertical Slice)

Status: Draft v1.0 (Phase 0 成果物 / Phase 1 実装のスコープ定義)
前提ドキュメント: `PIZZA_GAME_SSOT.md`（矛盾時はSSOTを優先）

## 1. スコープ

Phase 1 は「First Fun Pizza」の Vertical Slice。マルゲリータ1種類を、注文から図鑑登録・再プレイまで
最初から最後まで気持ちよく通せることを目的とする。

### 含む
- 単一レシピ（マルゲリータ）の注文〜完成〜採点〜図鑑登録の一連の流れ
- ソースを塗る操作（タップでピザ全体にトマトソースを塗布）
- チーズ・トッピングをピザ上の任意の位置にタップで配置する操作（複数個配置可能）
- 焼成のタイミング操作（ミニゲーム的な「焼き加減」判定）
- ミトの注文セリフ・ヒントセリフ、ブルーの試食コメント（テキストベース、音声なし）
- レシピ図鑑（今回は登録メンバー1件のみだが、後で増える前提のリスト表示）
- 「もう一度作る」によるリプレイ導線

### 含まない（`PIZZA_GAME_SSOT.md` 4章を参照）
- 複数レシピ・複数注文のローテーション
- 食材の購入・在庫システム（UIのボタンは配置してもよいが機能はダミー/非活性でよい）
- 経営指標（売上・評判など）
- セーブ/ロード、ログイン、通信

## 2. ゲームフロー（画面遷移）

Phase 1 は「原則1画面完結」の方針に沿い、ORDER〜RESULTまでを1つのメイン画面上のオーバーレイ／状態切り替えで表現する
（別ページへの遷移は行わない。SPA内の状態切り替えのみ）。

1. **ORDER**: 画面ロード時、ミトの吹き出しで「マルゲリータ」の注文がアナウンスされる。テトの掛け声が続く。
2. **PREPARE**: メインのピザ作成画面。プレイヤーは
   - 「ソース」タブでトマトソースを選択 → ピザをタップ（またはピザ全体に塗るボタン）でソースを塗布
   - 「チーズ」タブでモッツァレラを選択 → ピザ上の好きな位置をタップして配置（複数回可）
   - 「トッピング」タブでバジルを選択 → 同様に配置
   - 画面下部の「焼く！」ボタンは、レシピの必須食材が一定条件を満たすまで非活性 or 常時活性（Phase1は常時活性とし、
     未達なら結果が低評価になる形で自然にフィードバックする。詳細は DATA_MODEL のスコアリング参照）
   - 「やり直す」でトッピングをリセットできる
3. **BAKE**: 「焼く！」を押すと石窯アニメーションに切り替わる。焼き加減ゲージが動き、プレイヤーは狙ったタイミングで
   「取り出す！」をタップして焼成を確定する。
4. **RESULT**: ブルーが試食するイラスト・セリフが表示され、採点結果（★1〜3、3観点のスコア）が表示される。
5. **DISCOVERED**: 初回成功時は「レシピ図鑑に登録されました」演出を挟んでから図鑑を確認できる。以降は同レシピの再登録演出は簡略化してよい。
6. プレイヤーは「もう一度作る」ボタンで ORDER に戻れる。図鑑ボタンはヘッダーから常時アクセス可能。

## 3. 操作仕様

| 操作 | 入力 | 効果 |
|---|---|---|
| 食材カテゴリ切り替え | タブタップ（ソース/チーズ/トッピング） | 下段トレイの表示食材を切り替え |
| 食材選択 | トレイ内アイコンタップ | 「選択中の食材」として保持（ハイライト表示） |
| ソース塗布 | ソース選択中にピザをタップ | ピザ全体にそのソースの色/テクスチャを塗る（Phase1は全体塗り。部分塗りは将来拡張） |
| 具材配置 | チーズ/トッピング選択中にピザをタップ | タップ位置にその食材のアイコンを配置（複数配置可、配置しすぎ上限は緩い上限を設ける） |
| やり直す | やり直すボタン | PREPARE の配置状態を初期化（ソース・具材すべて削除） |
| 焼く | 焼く！ボタン | PREPARE → BAKE へ遷移 |
| 焼成確定 | BAKE中に取り出す！ボタン | ゲージ位置を記録し、BAKE → RESULT へ遷移してスコア計算 |
| もう一度作る | RESULT/DISCOVERED 内ボタン | 状態を初期化して ORDER へ戻る |
| 図鑑を開く | ヘッダーの図鑑ボタン | 図鑑オーバーレイを表示（どの状態からでも開閉可能） |

## 4. キャラクター発話のタイミング（Phase 1）

| フェーズ | 話者 | 例 |
|---|---|---|
| ORDER | ミト | 「マルゲリータが食べたいな！」 |
| ORDER | テト | 「よし、おいしいピザを作ろう！」 |
| PREPARE（未着手時） | ミト | ヒント: 「まずはソースを塗ってみて！」 |
| PREPARE（ソースのみ） | ミト | ヒント: 「次はチーズをのせよう」 |
| BAKE 開始時 | テト | 「いい香り…もう少し！」 |
| RESULT（高評価） | ブルー | 「最高だよ！また作って！」 |
| RESULT（低評価） | ブルー | 「うーん、次はもっとチーズを頑張ろう！」 |
| DISCOVERED（初回） | ミト | 「マルゲリータが図鑑に登録されたよ！」 |

セリフはすべて `src/data` 配下のデータとして持ち、UIコンポーネントにハードコードしない。
