## 2. A1 の定義

「すべて」（トッピング 56 種、10 ページ）の並びを、現行の**カタログ順**から、**ファミリーチップの並び順**（肉系 → 魚介系 → 野菜・きのこ系 → 果物系 → ハーブ・香味系 → スパイス・薬味系 → ちょっと変わった材料）で並べ、同じファミリー内はカタログ順のままにする。表示順だけの変更で、採点・保存・在庫・解放・ファミリー分類は変えない。

## 3. 評価（シミュレーション。実画面ではなく、実測した並びからの計算）

| 主効果 | P2 ファミリーが現れるページ数（平均） | 30% 以上減る |

### 3.2 結果（75 食材、56 トッピング、10 ページ）

| 指標 | 現行順 | A1 | 判定 |
|---|---|---|---|
| P1 1 ページあたりの異なるファミリー数（平均） | 3.50 | **1.60**（−54%） | 合格 |
| P2 ファミリーが現れるページ数（平均、7 ファミリー） | 5.00 | **2.29**（−54%） | 合格 |
| 補助: 1 ファミリーの全員を見終えるまでのページ送り（平均） | 7.71 | 6.00 | 改善 |
| G1 ページ送り（全食材平均 / 最大） | 4.18 / 9 | 4.18 / 9 | **同等**（並び替えではページ数は変わらないため構造的に同じ） |
| **G6 各ファミリーの初出までのページ送り（平均）** | **1.00** | **4.71** | **悪化** |
| G2 カタログに 1 件足したときにページが変わる既存食材（平均、全 56 中） | 0 | 3.0（約 5%） | 合格 |
| 参考: 同じとき、位置（ページ内のスロット）が変わる既存食材（平均） | 0 | 17.1（約 31%） | Owner 参考（基準外） |

ファミリー別の初出ページ（0 始まり、現行 → A1）: 肉系 1 → 0、魚介系 1 → 1、野菜・きのこ系 0 → 3、果物系 3 → 6、ハーブ・香味系 0 → **7**、スパイス・薬味系 2 → **8**、ちょっと変わった材料 0 → **8**。
A1 の各ファミリーが占めるページ（0 始まり）: 肉 0–1、魚介 1–3、野菜 3–6、果物 6–7、ハーブ 7–8、スパイス 8、その他 8–9。

### 3.3 操作数の比較（現行順 vs A1）

| 探し方 | 現行順 | A1 | 差 |
|---|---|---|---|
| 食材名を知っていて、「すべて」をページ送りで探す（全食材の平均 / 最大） | 4.18 / 9 回 | 4.18 / 9 回 | **なし** |
| 「ファミリーを知っている」人が、そのファミリーの食材に最初に会うまで（7 ファミリー平均） | 1.0 回 | 4.7 回 | **A1 が遅い**（ハーブ・スパイス・その他は 7〜8 回） |
| 同じ人が、そのファミリーの全員に会うまで（平均） | 7.7 回 | 6.0 回 | A1 が少ない |
| ファミリーチップで絞ってから探す（変更なし） | 平均 1.64 / 最大 4 | 同じ | **なし**（A1 の対象外） |

読み方: A1 は「すべて」の**まとまり**を良くするが、ページ送りの回数は減らさない。チップを使わない人にとっては、前のほうのファミリー（肉・魚介）は見つけやすくなり、後ろのファミリー（ハーブ・スパイス・その他、果物）は**初めて見えるまでが遠くなる**。チップを使えば元々 1〜4 回で着く。

## 4. 判定

- **主効果（構造）P1・P2 は合格。** ただしこれは「見た目のまとまり」の代理指標で、探す時間・誤りの減少を測ったものではない。
- **操作数（G1）は同等で、削減は確認できない。** 並び替えでページ数は変わらないので、構造的に減らせない。
- **G6 が悪化**（初出 1.0 → 4.71）。後ろのファミリーは「すべて」の前のほうで見かけなくなる。
- 位置の安定性（G2 の参考）: 新しい食材が入るたびに、A1 では平均 17 個の食材の位置（スロット）がずれる（現行は追記専用で 0）。ページが変わるのは平均 3 個。

**結論: 効果は「操作数の削減」としては確認できず、「まとまり」の改善と、後ろのファミリーの発見性の悪化がトレードオフになる。実装前 Gate を通過とは判断しない。したがって実装案は提出しない**（Owner 方針「効果が確認できた場合のみ」）。

## 5. 通過に必要な追加証拠（実装案を出す条件）

次のいずれかが得られたとき、実装案を提出する。

1. **課題ベースの実測**（実機 iPhone または Preview）: 「名前を指定された食材を『すべて』から見つけるまでのタップ数・時間」と「ファミリーだけ分かっている食材」を、現行順と A1 で比較する（ABBA 順、390×844 / 360×800）。#554 の実機枠と同じ機会にできる。
2. **G6 を解消する変形の提案**（例: 後ろのファミリーの先頭を各ブロックの前に仮見出しとして出す、など）。これは見た目の追加を伴い、高さ余白（`.ingredient-tray` 周り）を使うため、別の設計 Gate が要る。本 Gate では提案しない。
3. Owner が G6・位置の安定性を受容すると明示する（Owner の判断。その場合も、実機確認と本番 DOM golden の再基準化の理由を実装 PR に記す）。
