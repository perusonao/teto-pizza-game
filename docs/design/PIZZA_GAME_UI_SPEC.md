# PIZZA GAME UI Spec

Status: Draft v1.0
前提ドキュメント: `PIZZA_GAME_SSOT.md`, `PIZZA_GAME_MVP_SPEC.md`
ビジュアル参照: ユーザー提供モックアップ画像（テト・ミト・ブルーの店頭シーン）、
およびユーザー提供の3キャラクター単体イラスト（テト／ミト／ブルー）。
これらのキャラクターデザインはAIで描き直さず、提供画像をそのまま使用する。

## 1. 基本方針

- 対象: スマートフォン縦画面。基準幅 **390px**（iPhone 12/13相当）
- 原則1画面完結。ORDER〜RESULTのメインフローは同一画面内の状態切り替えで表現し、ページ遷移しない
- 世界観: 木製カウンター＋石窯のあたたかいピザ屋（暖色系、木目テクスチャ、手描き風フォント）
- 中央のピザが常に画面内で最大の視覚要素
- Web（マウス操作）でも同じUIでプレイ可能。タップ＝クリックとして扱う

## 2. レイアウト構成（縦方向、上から下）

```
┌─────────────────────────────┐
│ Header: ロゴ / DAY表示 / 所持金 / 図鑑ボタン / 設定  │ ← 固定, 高さ ~72px
├─────────────────────────────┤
│ Dialogue Area: キャラクター吹き出し（ミト/テト/ブルー） │ ← 可変, 高さ ~120-160px
├─────────────────────────────┤
│                               │
│      Pizza Stage（円形ピザ台） │ ← メインエリア, 画面幅いっぱい
│                               │   正方形に近いアスペクト比
├─────────────────────────────┤
│ Category Tabs: ソース / チーズ / トッピング          │ ← 高さ ~48px
├─────────────────────────────┤
│ Ingredient Tray: 横スクロール可能なアイコン一覧        │ ← 高さ ~96px
├─────────────────────────────┤
│ Action Row: 図鑑 / 焼く！(大) / やり直す / ヒント     │ ← 固定, 高さ ~88px
└─────────────────────────────┘
```

Phase 1 実装ではモックアップにある「食材の購入」ボタンは非活性のダミー表示でよい（経営要素は対象外のため）。

## 3. コンポーネント別仕様

### 3.1 Header
- ロゴ／タイトル: 「テトのピザ屋さん」
- 図鑑ボタン: タップで DexOverlay を開閉。未読の新規レシピがあればバッジ表示（Phase1は初回のみ）
- 所持金・DAY表示は Phase1 では静的なプレースホルダー表示でよい（経営要素は対象外）

### 3.2 Dialogue Area
- 発話中のキャラクターの顔画像（提供イラスト）を左または右に表示し、吹き出しでセリフを表示
- 複数キャラが同時に発話する場合は縦に並べる（モックアップ同様）
- フェーズが変わるたびに `dialogue.ts` の該当セリフに差し替える

### 3.3 Pizza Stage
- 円形の生地ベースを表示（Phase1はCSSで描画。木の台の上に生地が乗っているイメージ）
- ソースを選択してタップ/クリック → 生地全体にソースの色を乗せる（フェードインアニメーション）
- チーズ／トッピングを選択してタップ/クリック → タップ位置に食材アイコン（絵文字 or シンプルSVG）を配置
  - 配置位置はピザの円内にクランプする（円外タップは無視 or 円周上にスナップ）
  - 同じ食材を複数回配置可能。配置済みアイコンの再タップで削除できると気持ちよい（任意実装）
- BAKEフェーズ: ピザ全体に焼き色オーバーレイ＋ゆらめく炎エフェクト（CSSアニメーション）
- RESULTフェーズ: 完成したピザ＋星評価を表示

### 3.4 Category Tabs
- 3タブ: ソース（赤）／チーズ（黄）／トッピング（緑）— モックアップの配色を踏襲
- 選択中タブはハイライト（枠線＋背景色）

### 3.5 Ingredient Tray
- 選択中カテゴリの食材をアイコン＋名前で横並び表示
- 選択中の食材はハイライト表示
- Phase1はカテゴリごとに1〜数件のみ表示（トマトソース／モッツァレラ／バジル）。データにない食材アイコンは
  表示しない（データ駆動なので自動的に増減する）

### 3.6 Action Row
- 「焼く！」ボタンは常に画面内で最も大きく目立つCTA（モックアップ同様、炎アイコン＋赤系グラデーション）
- 「やり直す」でPREPARE状態をリセット
- 「ヒント」タップでミトのヒントセリフを表示（Dialogue Areaを更新するのみ、Phase1はシンプルに）

### 3.7 Bake Overlay（BAKEフェーズ）
- 石窯の炎アニメーション＋焼き加減ゲージ（横棒、0-100）
- ゲージ上のインジケーターが左右に往復
- 目標レンジ（perfectゾーン）を視覚的に示す（色分け）
- 「取り出す！」ボタンでそのタイミングのゲージ値を確定

### 3.8 Result Panel（RESULTフェーズ）
- ブルーの試食イラスト＋コメント
- 星評価（★1〜3）
- 3観点のスコアバー（注文一致度／材料の正しさ／焼き加減）
- 「レシピ図鑑を見る」「もう一度作る」の2ボタン

### 3.9 Dex Overlay（図鑑）
- 発見済みレシピをカード形式で一覧（Phase1は1件のみ）
- 未発見レシピは「？」のシルエット表示（将来のレシピ追加を見越した設計）
- 各カード: レシピ名、説明文、必要食材アイコン

## 4. カラー・トーン

- ベース: 暖色の木目（#8B5E3C系）＋クリーム色のカウンター（#F5E6C8系）
- ソースタブ: 赤系（#E4572E系）
- チーズタブ: 黄系（#F2B705系）
- トッピングタブ: 緑系（#4C9A2A系）
- CTA「焼く！」: 赤〜オレンジのグラデーション、炎アイコン
- フォント: 丸みのある手描き風の日本語フォント（Webフォントは軽量なものを検討。Phase1はシステムフォント+丸ゴシック寄せでも可）

## 5. アクセシビリティ・操作性

- タップ領域は最低 44x44px を確保
- 色だけに依存せず、選択状態はハイライト＋アイコン変化で示す
- テキストは日本語のみ（Phase1は多言語対応しない）

## 6. レスポンシブ

- 基準390px。360px〜428px程度のスマホ幅で崩れないこと
- PC/Webブラウザで開いた場合は、中央に390px幅のモバイルフレームを表示し、外側は背景色で余白を埋める
