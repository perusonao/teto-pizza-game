## 2. 設計（実物写真の特徴との対応）
1. **凹凸のある輪郭**: 極座標の境界 R(θ) ＝ 1 ＋ 低次調和（k=2〜5）＋ 広い舌状 1〜2 個 ＋ 切れ込み（湾）0〜1 個。星形で、凹（くびれ・湾）を持つ。シードの FNV ハッシュと xorshift（`Math.random` 不使用）で決定的。外形はシードの乱数列で、縦横比が 1.07〜1.34 に入るまで最大 24 回引き直す（決定的な棄却サンプリング。引き伸ばしは不要）。
2. **縦横比 1.06〜1.37**: 上記の棄却サンプリングで保証。**広がりは引き伸ばしではなく面積の拡大**: 半径は √(面積) で、面積は生の塊 38% から 100% へ滑らかに。形の不規則さも同じ曲線で育つため、途中の縦横比も生と完成の間に収まる。
3. **白飛びを抑えた乳白色**: 中心 (238,234,218) の艶消し、縁の内側は暖かく少し暗い (226,216,192)。艶は小さく途切れた照りのみ。
4. **中央の厚みと局所的な焼き斑**: 厚み場（ドーム＋縁で急に落ちる）を平滑化した高さから、左上光源の陰影（±4%）。縁は鋭い（縁の幅 約 3.5 ピクセル）。焼き斑は 1〜3 個の不規則なブリスター（琥珀の暈＋濃い芯。最初の 1 個は舌の薄い所）。`toast` で琥珀、`char` で茶、`char` で全体が焦げた灰褐色へ。舌の先は半透明（赤が透ける）。
5. **決定的**: 同じ入力は常に同じバイト列（冷たいキャッシュでも不変）。乱数・時刻を使わない（テストで検証）。
6. **軽量な構造**: ピクセルごとの極座標・角度ビン・ノイズ・ブリスター重みはシードごとに 1 回だけ前計算。描画ごとは「縮尺×厚み×照明×色」だけ。画像全体のメモ（量子化）つき。
7. **`prefers-reduced-motion`**: `options.reducedMotion` で一過性の変形（溶けの中盤の半径 +4.5% のオーバーシュート）を省く。完成形（melt 1）はどちらも同一。

## 6. コスト（Node、JIT 暖機後、デスクトップ。モバイルは 3〜6 倍遅いと見込む）
| 項目 | p50 | p95 |
|---|---|---|
| ジオメトリ構築（シードごとに 1 回、96×96） | 2.1 ms | 3.3 ms |
| 描画（ジオメトリ済み、1 個） | **0.88 ms** | 1.17 ms |
| 3 個を 1 回再描画 | 3.1 ms | — |
| メモのヒット | 0.0007 ms | — |
- 監査の見積り（3 個で 0.6 ms）より重い（実測は 3 個で約 3 ms）。照明用の平滑化（5 タップの箱ぼかしを 2 回）と、ピクセルごとの色計算が増えたため。モバイルで 3 個の再描画が 10〜18 ms になる恐れがあり、**S2 の性能合格基準（M1 比 +10% 以内）に対するリスク**。S2 での対策案: (a) グリッドを 64×64 にする（約 0.4 ms/個）、(b) 溶けの段階（24）を PREPARE→BAKE の空き時間に遅延生成してメモに入れる、(c) 不透明な内部の色計算を省く（バウンディングボックスと縁の帯だけ計算）。いずれも S1 では未実施。

## 7. 残る違和感・限界
1. **凸性は中央値 0.90 で、写真の 0.76〜0.84 より滑らか**。凹凸を強めると「スリット」や折り紙状の稜線が出たため、**自然さを優先してここで止めた**。写真は凹凸がより多い。
2. **形が「三つ葉・Y 字」に寄りやすい**（広い舌 2 個＋湾 1 個の構成のため、シードが違っても似た印象）。バリエーションの追加（舌の数・幅・曲がり）が S1 の延長で必要かもしれない。
3. 艶（油の照り・小さな気泡）はほとんど無く、表面がやや平板。写真の「縁の泡立ち」は未実装。
4. 舌の先の半透明が「ピンクのにじみ」に見える（写真では局所的）。
5. 焼き斑は小さな丸いにじみで、写真の「ブリスター」のような不規則な形・縁の焦げ付きは弱い。
6. 画像は Node で生成した画素（Chromium / WebKit のキャンバスでの見え方は未確認）。ゲーム画面の中の見え方（ソース・バジルとの重なり、CUT での見え方）は S2 以降。
7. 動き（オーバーシュート）は Proto3 の振付を踏襲した仮説。実機は未確認。
