## 1. 先に知っておくべき、24 simulation の読み方

比較の数字は、すべて PR #217 の 24 scenario から取っています。内訳は次のとおりです。
- 解放料カーブ 4 種: F0 / F1 / F2 / F3
- 工程の方式 3 種: A / B / C
- 品質 2 種: ★1 / ★3

**数字を読む前に、次の前提を押さえてください。**

1. **材料の解放条件の方式は変えていません。**
   - 24 本すべてで、同じ「混合プロファイル」を使っています。
   - 材料ごとに、⭐ / 発見数 / 累計完成数 / 累計獲得 Pitz を機械的に順番に割り当てたものです。
   - このため、「⭐だけ」と「混合」の差は数字では出ていません。この資料では定性的に比較しています。
2. **simulation の中では、条件そのものがボトルネックになりません。**
   - 条件の閾値は「それまでに発見できる量の 60%」以下に設定されています。
   - このため、詰まる原因は常に Pitz 不足です。
   - 焼き回数の差は、すべて「解放料と購入費の重さ」の差です。
3. **プレイヤーは完璧な知識を持っている前提です。**
   - 作れるレシピは、その瞬間に発見される扱いです。
   - 実際のプレイヤーが組み合わせを探す時間は含まれていません。「発見の楽しさ」は数字では測れていません。
4. **品質の前提は次のとおりです。**
   - ★1: 1 回焼くと 20 Pitz。新発見ならさらに +50 Pitz。1 回の発見で ⭐ +2。
   - ★3: 1 回焼くと 80 Pitz。1 回の発見で ⭐ +3。
   - ★1 は「下手なプレイヤー」、★3 は「上手なプレイヤー」の近似です。
5. **現行ゲームの ⭐ は「発見済みレシピの BEST★ の合計」です。**
   - つまり、既知のレシピを上手に焼き直すと ⭐ が増えます。
   - simulation は「発見するたびに固定の ⭐」で近似しています。BEST を更新して ⭐ を稼ぐ遊び方は再現していません。

用語（ここでは次の意味で使います）:
- **焼き直し (grind)**: 新しい発見のためではなく、Pitz を貯めるためだけに既知のレシピを焼くこと。
- **空白区間**: 新しいレシピを 1 つ発見してから、次を発見するまでの焼き回数。長いほど「何も起きない時間」が長いということです。

## 2. 材料アンロック条件（どの条件で「解放できる」状態になるか）

### 2.1 前提: 候補にしてよい条件は「減らない実績」だけ

循環やデッドロックを起こさない条件だけを候補にしています。PR #217 の validator がこの制約を検証しています。

| 候補 | 減らないか | 循環の危険 | 備考 |
|---|---|---|---|
| ⭐（BEST★ の合計） | 減らない | なし | 現行ゲームと同じ概念です |
| 発見したレシピの数 | 減らない | なし | |
| 特定のレシピを発見済み | 減らない | 条件つき | そのレシピを、この材料なしで作れることを材料ごとに証明する必要があります |
| 累計完成数 | 減らない | なし | 焼き直しでも増えます |
| 特定レシピの BEST 到達 | 減らない | 条件つき | 腕前で止まる人のために、代わりの道を用意する必要があります |
| Dex の到達数 | 減らない | なし | 実質的に発見数とほぼ同じです |
| Lunch Rush の累計提供数 | 減らない | 条件つき | Lunch Rush をやらない人のために、代わりの道が必要です |
| 累計獲得 Pitz | 減らない | なし | 使っても減りません。「所持金」とは別物です |
| ~~所持 Pitz / 在庫 / 連勝~~ | **減る** | **禁止** | 使うと条件を満たさなくなり、re-lock や循環の原因になります |

**複数の条件を組み合わせる場合:**
- **AND（全部必要）:** 安全です。ただし、一番遅い条件に合わせることになります。PR #217 は、生地やフライパンが必要な行について、工程の前提 (PREREQUISITE) を AND で必ず残すようにしています。
- **OR（どれか 1 つでよい）:** 各条件が単体で安全なら、OR にしても安全です。「好きな遊び方で解放できる」ことになります。
  - ただし、PR #217 の 24 本では **検証していません**。

### 2.2 方式ごとの、プレイヤーの感じ方

| 方式 | プレイヤーの体験 | 良いところ | 気になるところ |
|---|---|---|---|
| **⭐だけ** | 「上手に焼けば次が開く」。目標が 1 本の数字で分かりやすいです | 説明が最小限で済みます。今のゲームと地続きです。焼き直しで BEST を上げることにも意味が出ます | 一本道に感じます。腕前で止まる人は、同じピザを延々と焼き直すことになります。#218 で採点が変わると、解放のペースも一緒に変わります |
| **発見数** | 「新しいピザを見つけるほど、新しい材料が来る」 | 発見の楽しさと直結します。腕前に関係なく進めます | ⭐（BEST）を上げる動機が弱くなります。見つけられずに行き詰まったとき、打つ手が「探す」しかありません |
| **特定レシピの発見** | 「マルゲリータを極めたら〇〇が届く」のような物語を作れます | 材料とレシピの関係が記憶に残ります | 材料ごとに手で作る必要があり、作業量が増えます。循環がないことを 1 行ずつ証明する必要があります |
| **累計完成数** | 「たくさん作れば開く」。放置ゲーム的な安心感があります | 腕前にも発見にも左右されず、必ず進めます | 作業感が出ます。発見や BEST の価値が薄れます |
| **BEST / Dex / Lunch Rush / 累計 Pitz** | その遊びをやり込むことに報酬が付きます | モードごとに寄り道する理由になります | 単体でゲートにすると、そのモードを遊ばない人が詰まります。「OR の選択肢」か「一部の材料だけ」にとどめる必要があります |
| **組み合わせ（混合）** | 材料によって「次は⭐」「次は発見数」のように目標が変わります | 一本道感が減り、遊び方が分散します。PR #217 の検証で使ったプロファイルです | 「次に何をすれば開くのか」を UI で毎回示す必要があります。機械的に順番に割り当てると、材料と条件の組み合わせに意味がなくなります |

**補足（重要）:**
- simulation のモデルでは、⭐ はほぼ「発見するたびに +2〜3」で増えます。このため、**⭐だけと発見数は、数字の上ではほとんど同じ速さ**になります。
- 実際の差は次の 2 点です。
  - 焼き直しで BEST を上げたときに ⭐ が増えるか。
  - #218 の採点変更（不足したときの減点）で ⭐ が出にくくなるか。
- ⭐ を主軸にする場合は、#218 の結論が材料の解放ペースに直接効きます。

## 3. Pitz による材料解放の体験（具体例）

### 3.1 状態の流れ（プレイヤーから見たもの）

| 内部の状態 | Shop / 図鑑での見え方（例） | プレイヤーの気持ち |
|---|---|---|
| LOCKED | 🔒「⭐ があと 4 で解放条件達成」 | まだ先。何をすれば開くかは分かる |
| AVAILABLE_TO_UNLOCK | ✨「解放できます: 30 Pitz」 | 条件を達成した。お金を払うかどうか選べる |
| （解放料を支払う） | 「🥓 ベーコンを取り扱い開始！」 | 自分で選んで開けた、という手応え |
| AVAILABLE_TO_BUY | 「仕入れる: 60 Pitz / 30 個」 | 解放は済んでいる。あとは仕入れるだけ |
| OWNED | 冷蔵庫に在庫が並ぶ | 新しいピザを試せる |
| 在庫 0（OWNED のまま） | 「補充: 30 Pitz / 30 個」 | もう一度「解放」を払う必要はない。安心 |

**約束ごと（PR #217 で固定済み。この資料の判断対象ではありません）:**
- 一度払った解放料は永久に有効です（re-lock しません）。
- 在庫が 0 になっても「持っている材料」のままです。
- **解放料と初回の仕入れ代は別の支払いです。** 補充代も別です。

### 3.2 具体例: 🥓 ベーコン

数字は、PR #217 が検証に使った値（F2 = 中くらいの解放料、★1）です。最終的な値ではありません。

1. ゲーム開始時は、トマトソース・モッツァレラ・バジルを持っています。マルゲリータを焼いて発見します（+70 Pitz）。
2. ベーコンの解放条件は、検証用の混合プロファイルでは「レシピを 1 つ発見」です（⭐ の場合は「⭐2」）。これで条件を達成し、Shop に「✨ 解放できます」と表示されます。
3. **解放料 30 Pitz** を払います。これで、ベーコンがずっと Shop に並ぶ権利を得ます。
4. **初回の仕入れ 60 Pitz** を払い、ベーコンが **30 個**届きます（k=3。1 枚に 3 個使うので、10 枚分です）。
5. ブレックファストピザが作れるようになり、発見できます。
6. 在庫を使い切ったら、**補充 30 Pitz** で 30 個を補充します。解放料は二度とかかりません。

★1 のプレイヤーにとって、手順 3〜4 の合計 90 Pitz は、発見の報酬（+70）に加えて焼き直し約 1 回分です。解放料の重さによって、この重さが次のように変わります。

| 解放料カーブ | 序盤の材料（仕入れ 60） | 中盤（100） | 後半（140） | 終盤（180） | 序盤 1 材料あたりの焼き回数（★1。発見の 1 回を含む） |
|---|---|---|---|---|---|
| F0 なし（比較の基準） | 0 | 0 | 0 | 0 | 約 1 回 |
| F1 軽い（25%） | 20 | 30 | 40 | 50 | 約 1.5 回 |
| F2 中（50%） | 30 | 50 | 70 | 90 | 約 2 回 |
| F3 重い（100%） | 60 | 100 | 140 | 180 | 約 3.5 回 |

**生地とフライパンの扱い:**
- PR #217 の simulation では、生地とフライパン（13 個。合計 1,700 Pitz）に解放料はかかりません。仕入れ価格だけの「直接購入」として扱っています。
- これも 5 段階の流れに揃えるかどうかは、決まっていません（§6 を参照）。

## 4. 新しい工程（capability）の解放: A / B / C

対象は 11 の工程です。LAMINATE は現在の 101 レシピでは使われないため、休眠扱いです。代表例は次のとおりです。
- 生地を選ぶ（DOUGH_VARIANT）
- 重ね塗り（MULTI_SPREAD_LAYER）
- 焼いた後にのせる（LATE_ADDITION）
- フライパン焼き（PAN_BAKE）
- 包む（ENCLOSE）
- 手順の順番（STEP_ORDER）

| | **A_PAID（条件達成 → Pitz で購入）** | **B_AUTO（条件達成で自動解放）** | **C_TUTORIAL（初めて出会ったときに自動解放 + チュートリアル）** |
|---|---|---|---|
| プレイヤーの体験 | Shop に「🔧 新しい技: 重ね塗り 50 Pitz」が並びます。材料と技の両方にお金を払います | ある時点で「🎉 新しい技『重ね塗り』を覚えた！」と通知が届きます。使う場面はまだ先かもしれません | その技が必要なピザを初めて作れる状態になった瞬間に、「このピザは重ね塗りが必要です。やってみよう」とガイドが入ります |
| お金の負担 | 材料の解放料に加えて、技の料金もかかります（二重課金）。F2 で合計 +520 Pitz、F3 で +1,040 Pitz | 0 | 0 |
| 解放のタイミング（F2 / ★1 の例） | B とほぼ同じ時期です。ただし支払いのぶん焼き直しが増えます | 「生地を選ぶ」は 23 回焼いた時点、「手順の順番」は 32 回焼いた時点 | 「手順の順番」は **ゲーム開始直後**（トレントン・トマトパイの初回）。「生地を選ぶ」は 21 回焼いた時点（カリフラワー生地を買う直前） |
| チュートリアル感 | 弱いです。買った後に、使い道を自分で探す必要があります | 中くらいです。通知から使う場面までに間が空くことがあります | 強いです。「今、目の前のピザに必要だから覚える」ので、理由がはっきりしています |
| 分かりやすさ | Shop に技と材料が混ざり、選択肢が増えます | 最も単純です | 導線の設計が必要です。技が必要なピザに気づけないと、覚える機会が遅れます |
| 詰まりの危険 | 検証では 0 です。ただし、資金不足による足止めが最も長くなります | 0 | 0。PR #217 で「生地を買う前に教える」タイミングに修正済みです |
| 実装の重さ | 購入 UI、永続化、返金なしの原子的な処理が必要です | 永続化だけで済みます | 永続化に加えて、チュートリアル導線（ガイドの UI と、発火の判定）が必要です |

**PR #217 が推奨している「形」（最終決定ではありません）:**
- 生地やフライパンのような基礎の工程は B にします。
- 操作が独特な工程は C にします。
- 全部を A にするのは避けます。

- **「解放料の重さ」は、上手な人にとっては終盤の歯ごたえになり、苦手な人にとっては序盤からの足止めになります。** カーブを選ぶことは、どちらの層を優先するかを選ぶことでもあります。

## 6. まだ決めてはいけないもの（この資料でも決めません）

| 項目 | 理由 |
|---|---|
| **最終的な解放料の数値** | F0〜F3 は比率の候補です。#218 の採点（不足時の減点）と、品質ごとの Pitz 収入が固まる前に数値を決めると、やり直しになります |
| **最終的な ⭐ の閾値** | ⭐ は BEST★ の合計なので、#218 の採点変更がそのまま効きます。simulation は ⭐ を近似しているだけです |
| **最終的な ⭐ 以外の条件の閾値** | 現在の値は、検証のために機械的に割り当てたもの（それまでの発見数の 60%）です。材料ごとの意味づけはまだしていません |

### 質問 1. 材料は、主に何をすると解放されてほしいですか？（OD216-2）

| 選択肢 | プレイヤーの感じ方 |
|---|---|
| **A. ⭐だけ** | 「上手に焼けば開く」。分かりやすく、BEST を更新する動機が強くなります。一方で一本道に感じやすく、苦手な人は焼き直しで止まります。#218 の採点がペースを直接左右します |
| **B. 混合（⭐ / 発見数 / 完成数 / 累計 Pitz を材料ごとに割り当て）** | 「材料ごとに目標が違う」。一本道感が減ります。検証済みのプロファイルに最も近い選択肢です。ただし、割り当てに意味がないと「なぜこの条件？」と感じます |

| **D. ⭐ か 実績のどちらか一方で解放（OR）** | 「得意な遊び方で開けられる」。詰まりにくさは最も強いです。ただし 24 本では未検証なので、追加の simulation が必要です |

### 質問 2. 解放料は、どのくらいの「重さ」に感じてほしいですか？（OD216-1。方向性だけで、数値は決めません）

### 質問 3. 新しい工程（技）は、どうやって手に入ってほしいですか？（OD216-3）

### 質問 4. 「解放」と「初回の仕入れ」を、画面上でどう見せたいですか？（新しい論点。データ上は常に別の支払いです）
