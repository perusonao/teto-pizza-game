## iPhone Safari での確認手順
URL とバッジの SHA は PR のコメント（Result Report）に記載。**通常の Safari タブで開く（ホーム画面に追加しない）。** ページ上部のバッジが `PREVIEW・PR#875・<SHA>` で、コメントの SHA と一致するか確認。
1. 自由調理（またはパルミジャーノを選べるレシピ）で、生地 → トマトソース → チーズの段階でモッツァレラを中央に 2 つ置く。
2. トレイのパルミジャーノを選ぶ（**チップは従来どおり板のまま**であること）。
3. **3 か所タップ**: ピザ上の上（12 時）・左下（8 時）・右下（4 時）あたりを順にタップ。**確認 A**: 3 つの塊でなく、ひとつながりの散布に見えるか。タップ間（左右の橋）に薄片が届くか。中央の空きは残るか（残る見込み）。
4. **外周 4 か所タップ**（上・右・左・下の縁）。**確認 B**: 縁の近くに**大きな薄片**が出るが、皿の外へ大きくはみ出さないか。見た目が重くならないか。
5. 「1つ戻す」: 1 回で **1 件分だけ**消えるか。在庫の減り方が従来どおりか。
6. 焼く → 取り出す → RESULT: **確認 C**: 配置時と同じ散り方か。モッツァレラの白い面の上で見えるか。
7. **確認 D（CUT）**: パルミジャーノが選べて CUT のあるレシピ（例: クアトロ フォルマッジ。所持品が足りる場合）で、切り線の近くのパルミジャーノが、切られた隣のピースにも見えるか。（私の環境では実画面を確認できていない。数値では、切り線に掛かるピースが 27%→32% に増える。）
8. トレイのアイコンと他の食材が従来どおりか。
判定は Owner（PASS／FAIL／waived、日付と head の SHA つき）。**rev.6 の Preview ページは、公開枠（5 件上限）のため V8-1 の公開時に撤去する**ので、rev.6 との比較は上の画像と、Owner の rev.6 の HV（#875 comment 7029052653）で行う。
