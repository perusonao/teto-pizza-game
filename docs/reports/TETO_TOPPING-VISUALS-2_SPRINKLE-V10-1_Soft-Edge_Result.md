## 2. Style Lock との整合性
- 規則の原文: `docs/decisions/TETO_INGREDIENT-ICON-2.0_STYLE-LOCK-V2.md` §2（141 行）「SVG に `id` / gradient / `<defs>` を使わない（同一ページに何個あっても衝突しない）」、`aria-hidden`、`pieceVisual` のみを読む。64×64。
- **V10-1 は、`<svg>` ルートの CSS `filter: blur(0.4px)`（インライン style）だけ。`id`・gradient・`<defs>`・`url()`・`<filter>` 要素は新設・変更していない。** 同一ページに何個あっても `id` 衝突は起きない。字面は守られている。
- 注意: このロックは**アイコン用 SVG の規約**で、CSS の `filter` には明示的に触れていない（対象の描画は配置専用で、トレイ・ドラッグ・在庫・Dex は従来のまま）。プロジェクト内には CSS `blur()` の先例がある（ソース層 `App.css`）。**CSS フィルタをこのロックの範囲内と読むことの確認を、Owner にお願いする（§9 D1）。**
- 自動テストの番人: 描画結果に `id=`・`url(`・`<defs`・`Gradient`・`<filter`・`feGaussianBlur` が無く、64×64・`aria-hidden`・`focusable=false` が保たれ、`style` は svg ルートの 1 箇所だけ、子要素に style なし。
- 二重フィルタ: ラッパー `.pizza-cheese--parmigiano` の焼成フィルタ（明度・彩度・セピア）と、子の svg の blur は**別の要素**で、置き換えず両立する。実測（RESULT／CUT 画面）: svg `blur(0.4px)` ＋ ラッパー `brightness(1.06) saturate(1.12) sepia(0.14)` が同時に有効。
