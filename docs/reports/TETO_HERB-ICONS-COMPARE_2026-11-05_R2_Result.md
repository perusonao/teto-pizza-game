## 2. 見え方の指標を改めました

第 1 回の「平均明度差 ΔL」は、明るい縁と暗い輪郭が混ざる絵では打ち消し合って 0 近くになるため、**グレースケールでの見えやすさの指標としては不適切**でした（ほうれん草 A の焼成後 ΔL 2.8 はこの影響を受けています）。第 2 回は次を使います。

- **見える面積**: 背景（駒の周囲 3px の中央値）との色差 ΔE が 12 を超える画素の面積（px²）。
- **グレー面積**: そのうち、背景との明度差が **15 を超える**画素の面積（px²）。色を落としても残る部分で、グレースケールの見えやすさをよく表します。

## 4. 目視の所見（`docs/reports/screenshots/herb-icons-compare-20261105/herb-icons-compare-r2-*.jpg`）

- **アーティチョーク A2:** 外側の苞の内側に淡い黄緑の縁が入り、断面の層（外側の苞・内側の縁・淡い芯）がはっきりします。トレイの 26px でも縁が残ります。形は A のままなので、固定した判断を崩しません。
- **アーティチョーク A3:** 全体が薄い黄緑になり、グレースケールでは白い縁取りの付いた丸に見えます。溶けたチーズの上では背景に近づきます。
- **ほうれん草 A2:** 濃い緑の面に、薄緑の縁と白に近い葉脈が入ります。大葉（明るい単葉・鋸歯）、パクチー、バジルとは、色と 2 枚の葉の形で区別できます。縁と葉脈で、小さい表示でも葉の向きが分かります。
- **ほうれん草 A3:** 面も明るい緑になり、グレースケールの面積は最大ですが、緑の薄さがパクチー・大葉に近づき、**「ほうれん草らしい濃さ」が弱まります**。20px では 2 枚の葉が 1 つのライムのスライスに見えます。
- ローズマリー B・オレガノ B は固定のままで、前回と同じ見え方です。

## 5. 推奨と、Owner に判断していただくこと

1. **アーティチョーク: A2 を採用候補にする（推奨）。** A3 は不採用方向です。
2. **ほうれん草: A2 を採用候補にする（推奨）。** 識別性（濃い緑・2 枚の葉）を保ったまま、焼成後のグレースケールは A より約 4 割改善します。**ただし現行の絵文字のグレー面積には届かない**ことを認めたうえでの推奨です。現行の絵文字と同等以上のグレースケール視認性を必須とする場合は、A3 を選ぶか、A2 の中間色（面だけを少し明るくする）を作って再比較します。
3. 焼成後の見え方を補うために、ほうれん草へ `bakeRoastResistant`（焼き色を弱める、データの変更）を付ける案は、今回の見た目の改善とは独立で、必要性が確認できていないため**今回は提案しません**。
4. サイズ補正は既存のハーブ群と同じ 1.2em のままでよいか（推奨 Yes）。
5. 実装は #760 と #759 の merge の後（`IngredientGlyph.tsx`・`ingredients.ts` の claim）。`App.css` の補正が必要になる場合は、#765 と #761 の後（hot file）。
