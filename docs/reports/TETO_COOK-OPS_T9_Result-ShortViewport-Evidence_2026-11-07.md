## 0. 結論（先に）

1. **#766 と同種の現象を、別の再現手順で確認した**: 研究中（Research）の「オリジナルピザ」の RESULT（まだ新しいレシピは見つかっていない）で、**390×664・375×667・360×640 では「💡 ヒントを見る」が初期表示で下部の固定ボタン群の下に完全に隠れる**（`elementFromPoint` の 3 点すべてで固定バー側が返る＝**確認できた隠れ**）。390×844 では隠れない。
2. **スクロールで到達できる**（`.game-screen` は縦にスクロールする。末尾までスクロールすると「ヒントを見る」の下端は固定バーの上端より 35px 上）。**押せなくなるわけではない**（#766 の記述と一致）。
3. #766 の報告（重なり 17px／5px＝部分的な隠れ）より**今回の再現は大きい**（隠れ 54〜81px＝ボタン全体）。**再現条件が違う**ため（研究の結果表と材料チップ行が入り、ヒントの位置が下がる）。#766 の条件（材料違いで「？？？ピザ A（牛肉）」を研究中、モッツァレラ 2・しらす 4・大葉 2）そのものではない。
4. **別の RESULT（通常のマルゲリータ・ガイド付き、材料不足の失敗）では隠れは無い**: パネルの箱は固定バーの上端を超える（+19〜+46px）が、**内容（テキスト・ボタン）は何もバーの下に入らず、スクリーンショットでも欠けは無い**。**重なりの指標（箱）≠ 隠れ**であることの実例。

## 1. 方法

- 起動: ローカル dev サーバー（Vite、Chromium、`isMobile`・タッチ・DPR 2）。viewport: 390×844、390×664、375×667、360×640（#766 の列に合わせた）。
- **(A) 研究中の非一致ピザの RESULT**: State Editor の「All Ingredients」を適用 → ホームの「レシピ発見」→ 研究カードの 1 つで自由調理（研究対象は表示「研究中 ？？？ピザ（たまご）」）→ 生地 8 タップ → トマトソースを渦巻き → モッツァレラ → トッピングにコーンを 2 個 → 焼いて約 2.1 秒で取り出し →「完成」→ RESULT。
- **(B) 通常の RESULT**: ガイド付きのマルゲリータ → 材料の一部を置かずに焼く → 3 本切る →「切り終わる →」→ RESULT（結果は「失敗・バジルが入っていません」）。
- 測定: 固定バー（`.action-row`）の上端、「ヒントを見る」の矩形、`elementFromPoint` による**隠れの判定**（ボタンの上端近く・中心・下端近くの 3 点がバー側の要素を返すか）、`.game-screen` の `clientHeight`／`scrollHeight`、スクロール後の位置。
- 目視: 上記の PNG を確認。

| viewport | バー上端（高さ） | 「ヒントを見る」上端〜下端 | **下端 − バー上端** | `elementFromPoint`（上・中・下） | `.game-screen` | スクロール後（末尾） |

| 判定 | 意味 | 本件 |
