### テストの見直し（緩めたのは 2 つだけ、理由付き）
- 陰影のばらつき（折れ目・稜線の指標）の上限 1.1 → 1.3。厚い縁の陰影は意図したもの。折れ目なら 1.3 を大きく超える（400 シード実測の最大 1.22）。
- 芯の色の許容 ±5 → ±6（陰影の強化でシードごとの平均が僅かに動く）。
- 白飛び（輝度 >246）は最大 0.2%（上限 7%）、焼き色の暖色画素は toast 0.6 で中央値 3.2%・p95 5.1%・最大 6.6%（S2-A は 2.8% / 4.3% / 5.1%）。いずれも S2-A 時点のテスト基準内。

## 6. CUT〜RESULT の +30% の切り分け
**結論: 再現できず、Canvas 単体・SVG フィルタ併用・CUT 複製のいずれにも、ノイズを超える増加は検出されない。S2-B の +30% は、モードを順に（M1 → 64 → 96）流した計測の順序・環境のずれによる見かけと判断する。ただしそのずれの正体は特定できていない（未特定）。**

方法: 同じマルゲリータ 1 周を、バリアントごとに交互に（`m1 → m1-again → m1-nofilter → c64 → c64-nofilter → c64-hidden → c64-nofilter-hidden` を 1 ラウンドとして 7 ラウンド）、1×、実時間で実行。CUT の 3 回のドラッグ + 「切り終わる」〜RESULT のメインスレッド処理時間（CDP `TaskDuration`）の中央値。
| バリアント | 内容 | CUT 合計（ms） | M1 比 | 最小〜最大 |
|---|---|---|---|---|
| m1 | 既存 CSS | 477 | 基準 | 325〜558 |
| **m1-again** | **m1 と同一（ノイズの目安）** | 559 | **+17%** | 266〜643 |
| m1-nofilter | M1、ピースの SVG フィルタ無し | 512 | +7% | 323〜623 |
| c64 | Canvas 64（SVG フィルタ有り、通常） | 491 | **+3%** | 287〜690 |
| c64-nofilter | Canvas 64、SVG フィルタ無し | 536 | +12% | 351〜667 |
| c64-hidden | Canvas 64、キャンバスを `visibility:hidden`（要素と複製は有るが描画しない） | 522 | +9% | 332〜600 |
| c64-nofilter-hidden | 両方 | 517 | +8% | 332〜688 |
- **同一条件の M1 同士の差が +17% あり、これは各バリアントの差より大きい**。標準の c64 は M1 比 +3%。
- SVG フィルタを外しても、キャンバスを描画しなくても、c64 の値は下がらない（フィルタ有りの c64 が最小）。複製（5 個のキャンバス）は「hidden」でも同数残るため、複製そのもの・描画のどちらにも増加は見られない。
- 区間別（ドラッグ / 完了〜RESULT / RESULT 静止）でも、スクリプト時間は同等（65〜70 ms / 23 ms / 0.3 ms）、Raster・Paint・Layout・スタイル再計算に Canvas 固有の差は無い。差が出るのは Commit（コンポジタ）の揺らぎ（M1 同士でも 67〜90 ms）。
- 参考: 1 回目の分離実験（バリアントごとに連続実行、各 6 回）では c64 は M1 比 −4%（355 ms 対 370 ms）、S2-B の +30%（377 → 492 ms）は M1 → c64 → c96 の順で連続実行した結果で、順序・環境のずれが混ざっていた。
- **未実施（Owner の確認なしに長時間測定を始めないため）**: 4× スロットルでの再測定、実機・WebKit での測定。
- 対策: 現時点では不要（増加要因が見つからないため）。もし実機で CUT〜RESULT の増加が見つかったら、順に (1) キャンバス要素の数を減らす（切れ目をまたがないピースの複製をスキップ。ただし CUT の既存複製構造は変えない前提のため要相談）、(2) キャンバスをビットマップ画像（`<img>`）に置き換える、(3) 描画を `will-change` なし・`contain: paint` に、が候補。

## 7. 残課題（S2-B2 時点）
1. 色は M1 の鮮やかな白・白い縁取りより落ち着いた象牙色（乳白色の基調は維持という方針どおり）。ゲーム内の他の素材と並べると M1 の方が目立つ。
2. 約 41 px の表示では焼き斑・金色のまだらは小さく控えめ（拡大すると見える）。
3. 密集配置ではチーズ同士が 1 つの塊に見える（ピース融合は S3 の範囲）。焼き上がりの直径は M1 比 +39% なので、M1 より重なりやすい。
4. **WebKit・実機は未検証**（コンテナに WebKit が無い）。動画もヘッドレス Chromium のソフトウェア描画で、実機の滑らかさとは異なる。
5. CUT〜RESULT の 4× 再測定は未実施。
