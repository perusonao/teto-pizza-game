### 約 24px の貝（H11、`pieces-24px-before-after-4x.png`）
- ピース実寸 **24×29 CSS px**。蒸し前は灰ベージュ、蒸し後はやや明るいクリーム色＋ふちにごく薄いピンク。**形は同じ閉じた貝**。

- 「開いた貝」を連想させる要素は、ピース上にはない（開いた表現はモーダル内のみ）。ピザ上の手掛かりは「✓ 蒸し済み」ピルだけ。
