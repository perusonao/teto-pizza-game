## 再現（検査コード全文）

`python3 -I check.py`（入力は同じディレクトリの `T25-R2b.preflight.md` と `T25-R2c.preflight.md`。基準 commit: preflight は `cf0c865` で実行、`03f32e1` ではカタログ不変）。

```python
import re
D = "docs/reports/data/TETO_T24-T26_PREP/"
def rows(f):
    s = open(D + f).read(); s = s[s.index("## 4. Research"):s.index("## 5.")]
    r = {}
    for l in s.splitlines():
        m = re.match(r"\| `([a-z0-9-]+)` \| (.*?) \| (.*?) \| (.*?) \|$", l)
        if m:
            st = dict(p.split(": ", 1) for p in m.group(2).split("; "))
            r[m.group(1)] = (st, m.group(3), {x.strip() for x in m.group(4).split(",")})
    return r
b, c = rows("T25-R2b.preflight.md"), rows("T25-R2c.preflight.md")
bad = []
for k, (st, al, cb) in c.items():
    if k not in b: bad.append((k, "ID not in R2b")); continue
    bst, bal, _ = b[k]
    for s_, v in st.items():
        if s_ not in bst: bad.append((k, "stage not approved", s_))
        elif bst[s_] != v: bad.append((k, "shift differs", s_))
    if al != bal and al not in bal: bad.append((k, "allowed", al))
    if "chicken-tikka-pizza" in cb: bad.append((k, "still caused by tikka"))
dropped = [k for k in b if k not in c]
print(len(b), len(c), "violations:", bad)
print("dropped", len(dropped), all(b[k][2] == {"chicken-tikka-pizza"} for k in dropped))
```

各行は ① ID が R2b にある ② R2c の各 stage が R2b の同じ行にあり文言（`later by at most N` / `new first letter only`）が同一 ③ `caused by` に chicken-tikka-pizza が無い、を検査する。「正準順の変化 0」は preflight 自身の出力行（`T25-R2c.preflight.md` §4 冒頭）の引用で、本スクリプトでは再計算していない。
