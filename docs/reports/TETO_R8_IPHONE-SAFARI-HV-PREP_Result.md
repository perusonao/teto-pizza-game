```js
(() => { const real = Storage.prototype.setItem; window.__failSave = true;
  Storage.prototype.setItem = function (k, v) { if (k === "teto-pizza-preview-save-v1" && window.__failSave) throw new DOMException("quota", "QuotaExceededError"); return real.call(this, k, v); }; })();
```

## 8. Owner に必要な判断

1. **確認環境**：83f4b55 を載せた Preview を用意する方法。(a) 共有 Preview を 83f4b55 で更新する（現在の `224672d`／PR #582 を記録し、実施後に必要なら元の SHA で再デプロイ）。(b) per-PR Preview（別保存名前空間／別 origin、Phase 1B）の実装を先に行う。(c) 本件は実機 HV を保留する。

3. **Lunch Rush の自動テスト**：実機の前に、Lunch Rush の Chromium／WebKit E2E（G-1〜G-5 相当）を追加する別 Issue を起こすか。runtime／e2e は本作業では変更しない。
4. **実機の範囲**：ホーム画面追加（H-2）、実容量超過（E-5）、未知版 journal（E-6）を必須にするか任意にするか。
5. **動画の受領**：`r8-pending-round_hv_390x844.mp4` を Owner が受領済みか（本セッションでは確認できません）。
6. **不整合の訂正**（§2.3）を docs-only の別 PR で行うか。
