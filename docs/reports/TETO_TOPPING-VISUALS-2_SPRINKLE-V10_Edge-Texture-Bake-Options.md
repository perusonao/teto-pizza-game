## 2. 原因の整理（コードと測定による。実機の知覚で確定したものではない）
1. **輪郭の「線」は髪の毛ほどの細さで、弱めても効かない。** `strokeWidth = 0.14〜0.30`（viewBox 単位、1 単位 = 1.5 CSS px）＝約 0.2〜0.45 CSS px、`strokeOpacity` は 0.22〜0.52。強さを 1/4 にしても、焼成後の集計は割合 −1pt・ΔE −0.2・面積 −3% しか動かない（下の O 案）。
2. **「明瞭な輪郭」の正体は、塗りの縁そのもの。** 塗り（不透明度 0.8）は縁で急に切れる。輪郭帯と内側の ΔE の比は、焼成後で 0.52（配置時 0.38）。その縁は 9 頂点の多角形（角の丸め 0.3）で、F3 の幅/長さ 0.28〜0.55 だと**ほぼ平行な直線 2 本の細長い形**（長さ 10.5〜17 に対し幅 3〜9）になる。リボン（長さ ≥12、幅 3.4〜5.6）も元から短冊状。**「木片・短冊」は F3 で細くしたことと、縁が直線的でぼかしがないことの組み合わせ**と考えられる。
3. **焼成では描画そのものは変わらない。** 焼成で変わるのは、ラッパー `.pizza-cheese` の `scale`（最大 1.16）と CSS フィルタ（明度 1.06・彩度 1.12・セピア 0.14）だけ。実測（RESULT）: `--bake-melt-scale` = 1.159、`filter: brightness(1.06) saturate(1.119) sepia(0.139)`。配置時は未設定（＝1）。**溶けたモッツァレラは別に描かれる白い面**で、その上に黄みが増した薄片が**変わらない縁**のまま載るため、「なじまない」。
4. **白地での見え方は、輝度ではなく色味（黄み）に支えられている。** 色味を打ち消すと、白地で明瞭に見える割合は 40%→1% に落ちる（B 案）。つまり「なじませる」ことと「見える」ことは同じ軸の逆方向で、**どの「なじませる」案も、白地で消える崖と隣り合わせ**になる。

## 3. 既存の F1・F2・F3 の検証結果との照合
- **F2（質感の束）の分解**（F3 を土台に再測定）: F2 は不透明度 0.6・輪郭×0.5・影×0.5・芯なし・木目なしの 5 ノブの束だった。**不透明度 0.6 だけ（T1）で、F2 の束（f2b）とほぼ同じ結果**（白地の明瞭な割合 9% と 7%、ソース上 ΔE 33.4 と 32.8）。輪郭・影・芯・木目の寄与は、ほぼ 0。→ **F2 で白地で消えた原因は不透明度**で、輪郭・質感の線ではない。
- **F1（サイズ）・F3（幅）**: 描画の塗りは変えていない。F3 は白地の明瞭さを維持（V8-1 42% → F3 40%）したが、縁の鋭さは変えない。
- 結論: 輪郭・質感の線を調整しても効果は小さい。効くのは **(a) 縁のぼかし（形の縁）**、**(b) 焼成時に変える量（ただし崖あり）**、**(c) 形（短冊）**。
