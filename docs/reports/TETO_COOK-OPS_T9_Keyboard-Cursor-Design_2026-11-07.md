## 0. 位置づけと範囲

- **対象**: (1) C-A′（CUT の「点で切る」）の**点の指定**、(2) S-A（スタンプ）の**ガイド点の選択**（S-A は未決のため「将来の入力」として共通化できる形だけ示す）。D-A′（生地）はすでにボタン／キーボード向け（方向巡回の＋／−）なので**カーソル不要**。
- **原則**: カーソルは**新しい意味を作らない**。`POINT(x, y)` のような既存の純粋イベントの**座標の出所を増やすだけ**（C-A′ の状態機械は座標の出所を問わない）。ポインタの結果と**同じ**になる（C2）。
- **今は設計のみ**。UI・フォーカス処理・CSS・イベント配線は実装しない。

## 1. いつ「キーボードのモード」になるか（タッチでは強制しない）

| 場面 | 判定 | フォーカス |
|---|---|---|
| 見出し「別の操作方法を使う」を**キーボードで**起動（Enter／Space） | `click` イベントの **`detail === 0`**（キーボード起動の合図。**既存の先例**: `CookingPrepLayer.tsx` のピルは「Enter／Space のときだけ」`event.detail === 0` を見て開く） | **開いた先の最初の操作へフォーカスを移す**（Owner 決定） |
| 見出しを**タッチ／マウス**で起動 | `detail ≥ 1` | **フォーカスを動かさない**（通常のタッチでは強制しない） |
| VoiceOver の二本指ダブルタップ等 | `detail` が 0 か 1 かは**ブラウザ・支援技術により異なる可能性**【未確認】 | 0 のときはキーボード扱い（フォーカス移動）。**VoiceOver でフォーカスが移ることが不都合かは実機で確認** |
| スイッチコントロール | 同上【未確認】 | 同上 |

- **キーボードのモードに入ったあと**だけ、点指定のカーソルがキーに反応する（常時ではなく、カーソル面にフォーカスがあるとき）。
- 閉じるとき（Esc または見出しの再起動）は、**フォーカスを見出しに戻す**（キーボード起動のときのみ）。タッチ起動のときは戻さない。

## 2. カーソルの設計

### 2.1 カーソル面（フォーカス可能な 1 要素）

- 生地の上に重ねる**フォーカス可能な 1 要素**（`tabindex="0"`、`role="group"`、`aria-roledescription="点の選択"`）。`role="application"` は使わない（ブラウザのキー処理を奪いすぎるため）。
- **ポインタ操作（タップ・スワイプ）は通さない**（`pointer-events: none` ではなく、生地側の既存の操作を妨げない配置。実装時に検討）。
- フォーカスが来たとき、カーソルを**生地の中心（50, 50）**に置く（始点を選ぶ前）。始点を置いた後は、**始点の位置から**始める（終点を選びやすい）。

### 2.2 キー操作

| キー | 動作 | 備考 |
|---|---|---|
| ↑↓←→ | カーソルを **1 ステップ**移動（既定 **2.5 単位**＝箱 100 のうち）。生地の円内にクランプ | 箱が約 330px のとき 1 単位≈3.3px、1 ステップ≈8px（目安） |
| Shift＋矢印 | **粗い移動**（**10 単位**） | 縁へ素早く行ける |
| Alt／Option＋矢印 | **細かい移動**（**0.5 単位**） | 位置合わせ。最小長 8 の判定に便利 |
| Home | 中心（50, 50）へ | |
| Enter／Space | **`POINT(x, y)` を発行**（始点／終点／終点の差し替えは状態機械が決める） | **押しっぱなしの自動リピートは無視**（`event.repeat`。1 押下＝1 点。既存の `PizzaStage.handleKeyDown` と同じ規則） |
| Esc | アームを解除せず**点だけ消す**（`CLEAR_POINTS`）。点が無いときは**開閉をたたむ** | 2 段階の Esc。読み上げで案内 |
| Tab／Shift＋Tab | ブラウザ既定（カーソル面 → 「切る」→「やめる」→ …） | カーソル面でフォーカスの罠を作らない |
| 「切る」ボタン（Enter／Space） | `commitCutAlt` | 2 回目の Enter で自動確定はしない（Owner 決定: 明示の「切る」） |

- ステップ幅 2.5／10／0.5 は**暫定値**。実機のキーボードでの体感で調整【未確認】。
- 円の外へは出ない（クランプ）。縁スナップは**しない**（Owner 暫定）。縁を指定したいときは円周近くまで矢印で動かす。
- **範囲を超えた移動は何も起こさない**（音・振動なし。読み上げのみ「これ以上いけません」）。

### 2.3 カーソルの純粋ロジック（将来の設計。実装しない）

```ts
export interface CutCursorState { x: number; y: number }   // 箱の単位 0..100。生地の円内
export type CutCursorEvent =
  | { type: "MOVE"; dx: -1|0|1; dy: -1|0|1; scale: "fine"|"normal"|"coarse" }
  | { type: "HOME" }
  | { type: "FOCUS"; from?: { x: number; y: number } };     // 始点があればそこから
export function cutCursorReduce(s: CutCursorState, e: CutCursorEvent): CutCursorState;
// Enter/Space は状態機械側へ: cutAltReduce(state, { type: "POINT", x: s.x, y: s.y })
```

- `x, y` は常に `Math.hypot(x-50, y-50) ≤ DOUGH_RADIUS(48)`（`cutAltReduce` の `isOnPizza` と同じ範囲）。範囲外への移動は円周上の最も近い点へ**クランプ**（`isOnPizza` が弾く点を作らない）。
- 時刻・DOM を知らない純粋関数。**`cutAltMachine` はそのまま使える**（`POINT` を受けるだけ）。

## 3. 読み上げ（C10）と色以外の手掛かり（C12）

### 3.1 位置の言い方（座標の数字を読まない）

2 次元の座標は読み上げに向かない。**方向（8 方位）＋中心からの距離（3 段階）**で言う:

| 距離（中心から、半径 48 に対する割合） | 言い方 |
|---|---|
| 0〜0.2 | 「中心」 |
| 0.2〜0.6 | 「中ほど」 |
| 0.6 以上 | 「ふち近く」 |

例: 「右上、ふち近く」。始点・終点が置けたら「始点を置きました。右、ふち近く」「終点を置きました。左、ふち近く。線の長さ OK」。最小長（8）未満は「もう少し離れた場所を押してください」（`CUT_ALT_PHASE_TEXT_JA.too-short` と同じ）。

- 移動のたびに読み上げると冗長なので、**移動は 250ms まとめて**（最後の位置だけ）。`aria-live="polite"`。
- 範囲の端: 「これ以上いけません」。
- 完成したら: 「線を引きました。残り N 本」（既存の進捗表示と同じ言い回し）。

### 3.2 見た目（色だけに頼らない）

- カーソル: **十字（＋）の記号**（太さ・形で目立たせる）。フォーカスリングはブラウザ既定を消さない。
- 始点＝○、終点＝□（C12。C-A′ の既存設計と同じ）。
- 結ぶ線は**破線**（確定前）→ 実線（切った後）。色の違いだけにしない。

## 4. S-A への展開（将来。S-A が決まるまで設計のみ）

S-A の「ガイド点」は離散的な点の集合なので、**カーソルの自由移動より「次の点／前の点」**のほうが合う:

| キー | 動作 |
|---|---|
| ←→（または ↑↓） | ガイド点を **1 つずつ巡回**（強調は輪郭の二重丸＋文言） |
| Enter／Space | 強調中のガイド点を**スタンプ**（`SAUCE_STAMP(index)`） |
| Backspace／Delete | 直前のスタンプを戻す（S7: 取り消しが決まれば） |

- **ガイド点の数・位置・重複の扱い（S1〜S7）は未決**。ここでは「入力の形」だけを決める（巡回＋確定）。点の数・配置が決まるまで、読み上げの文言（「右上に置きました。全体の 40%」）も確定しない。
- 任意位置タップ（ガイド無し）が採用された場合は、本書の §2（カーソル方式）をそのまま使える（`POINT` 相当のイベントを発行する）。

## 5. スイッチコントロール・VoiceOver

- **スイッチコントロール**: 順次走査では、カーソル面は 1 つの要素として扱われ、矢印キーは使えない。**代替として「方向×距離」の離散操作**（下表）をボタンで用意する案:

| 操作 | ボタン | 備考 |
|---|---|---|
| 方向 | 「次の方向 ▶」「◀ 前の方向」（8 方位） | D-A′ の方向巡回と同じ作り（部品を共通化できる） |
| 距離 | 「内側へ」「外側へ」（中心・中ほど・ふち近くの 3 段階。または 5 単位刻み） | |
| 確定 | 「ここに点を置く」 | `POINT` を発行 |

- **VoiceOver**: カーソル面（フォーカス可能な要素）にフォーカスがあるとき、**VoiceOver が矢印キーを横取りする**ことがある（Safari＋外付けキーボードでは Ctrl＋Option＋矢印が既定）。**実機で確認が必要**【未確認】。上の「方向×距離のボタン」が、**矢印が使えない環境の安全網**になる。
- **両方を持つ**: キーボード（矢印）と離散ボタン（方向×距離）は**同じ `POINT`** を発行するので、状態機械は変わらない。
