### 経路 C の注意（Owner 判断が必要）

- State Editor は**共有 Preview の保存キー（`teto-pizza-preview-save-v1`）を書き換える**。この鍵は全 Preview ビルドで共有され、Owner が Preview で進めている状態があれば変わる。**これは「共有 Preview の更新（デプロイ）」ではないが、端末内の Preview 進行データを書き換える操作**。
- プリセット適用の内容（リハーサルの確認画面）: Pitz 0→300、材料 94 件を OWNED、在庫を各 10、「最後に取得した材料」が変わる（Research Entry の unlock fact に影響する旨の警告が出る）。
- 保護: 適用前に raw のまま backup（`original`・`previous`）。適用後は本物の loader で検証される。**元に戻すには バックアップ → 復元**。Owner の Preview 進行を残したい場合は、**適用前に必ず「バックアップ」タブで `original` が作られたことを確認**。
- 回避案: Owner の Preview 保存が空（または捨ててよい）端末／ブラウザプロファイル（例: プライベートブラウズ）で行う。**ただし localStorage のオリジンは `perusonao.github.io` で本番と共有**（Preview は別キーなので本番の保存は触れない）。

## 3. 最短手順（経路 C。リハーサルで通した順）

前提: iPhone Safari、縦、アドレスバー／タブバー表示のまま。以下 URL は共有 Preview `https://perusonao.github.io/teto-pizza-game-preview/` の下。

1. `?dev=state` を開く。
2. タブ「**プリセット**」→「**All Ingredients**」→「**確認して適用へ**」。
3. 適用タブで「上の変更内容と backup を確認しました」を ON → 「**適用する**」。結果に「適用しました（本物の loader で検証済み）…元の save を backup（original）しました」が出ることを確認。
4. ゲームを開く（結果の「ゲームを開く」リンク、または Preview のトップ）。ホームの「**🎨 レシピ発見**」。
5. Dex の研究カードが出るので、どれでも「**🔎 このピザを研究する**」（フリークッキング。研究対象はヒントの題材のみ。ここで選んだピザは今回の計測に無関係）。
6. **生地**: 生地の縁の 8 か所（ほぼ等間隔）を**1 回ずつタップ**。「次へ →」が有効になったら押す。【リハーサル: 縁の 8 点を円周の 46％半径でタップして有効化】
7. **ソース**: 「トマトソース」を選び、生地の上を渦巻状に約 1.5 秒なぞる → 「次へ →」。
8. **チーズ**: 「モッツァレラ」を選び、生地の 5 か所をタップ → 「次へ →」。（クリームチーズ・フェタ・リコッタを見たい場合は、ここでそれらのチップを探して置く。**未確認**）
9. **具材**: 計測したい食材のチップを選び、生地の別々の場所をタップして置く（食材ごとに 1〜2 個。ピザ上で重ならない位置）。
   - **近道**: ファミリータブ（魚介系／野菜・きのこ系／ハーブ・香味系／スパイス・薬味系）を使うと探しやすい。「すべて」は 12 ページある。
   - **落とし穴【リハーサルで遭遇】**: 後ろのページにいる状態で「すべて」を押してもページが先頭に戻らない場合がある。見つからないときは「◀」で戻すか、ファミリータブを使う。
10. 「**🔥 焼く！**」→ 針が動く間に**画面録画**する（§4）。
11. 「取り出す！」→ （FINISH があれば）「完成」→ RESULT。【リハーサルは焼成中まで。以降は未確認】

操作回数の目安（リハーサル）: 手順 2〜3 で 4 タップ＋チェックボックス 1、手順 4〜5 で 2 タップ、手順 6〜8 で約 20 タップ＋渦巻き 1、手順 9 は食材数 × 2 タップ。

## 4. 焼成段階の取り方（1 回の録画で全段階を撮る）

- 焼成の針は **0→100 を約 3 秒**（`BAKE_DURATION_S = 3`）。リハーサルの実測: 約 32 点／秒（t=2188 ms で 70.6、t=2896 ms で 93.9）。
- **焼成中のピザ上の具材は、針と一緒にフレームごとに見た目が更新される**（`bakeVisual.ts` の連続曲線）。リハーサルのスクリーンショットでも、針 70 付近の画面で具材が表示されていた。よって **5 回に分けて止めるのではなく、1 回の焼成を画面録画し、コマ送りで各段階を切り出す**のが最短。
- 目安の針の位置（フリークッキングの窓は `FREE_COOK_BAKE_TARGET`＝各レシピの start／end の中央値。**リハーサルでは recipes.ts の 82 レシピから約 {58, 78}（中心 68）と推定。画面のゲージに実際の窓が出るので、それを優先**）:

| 段階 | heat | 針（中心 68 の場合） |
|---|---|---|
| H0 | 0 | 焼成前（針 0） |
| H1 | 0.8 | 約 54 |
| H2 | 1.0 | 約 68（ゲージの中央） |
| H3 | 1.6 | 約 87 |
| H4 | 2.0 | 100（右端） |

- 手で「取り出す！」を押して止める必要はない（録画で足りる）。**針が 100 に達した後の挙動（自動で終わるか、焦げ確定か）はリハーサルで未確認**。Owner が実機で観察して記録する。
- 録画の再生速度が 3 秒しかないため、コマ送りが難しい場合は同じ手順を 2〜3 回繰り返して、気になる段階の前後を撮る。
