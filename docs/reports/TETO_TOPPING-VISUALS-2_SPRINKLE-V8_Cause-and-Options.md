## 0. 先に結論

1. **塊に見える主因は「半径が足りない」ことと、rev.6 で足した B の部分（欠片 4〜5 を外側の位置へ割り当てる構造）が半径の効果を打ち消していること。** Owner の 3 タップは互いに 116〜132px 離れているのに、rev.6 の散布が実際に「見える」大きさ（インクの 80% が入る半径）は約 43px、直径 約 86px しかない。タップ同士の間に約 30〜46px の空白が残るのは、この幾何から説明できる。
2. rev.5 → rev.6 の変更を 1 つずつ分離すると、**半径 30→34 は橋（タップ間の中間）に届く薄片を大きく増やした（橋が架かる割合 46%→76%）が、欠片を 4〜5 個に増やして外側の位置へ割り当てたことで 76%→55%、FADE 2.2 でさらに 50% まで戻った**。結果として rev.6 は rev.5（44%）より 6 ポイントしか良くない（橋の片数は 0.53→0.63）。
3. **最も安く効くのは、欠片を外側 60% ではなく、全体の位置から割り当てること**（橋が架かる割合 50%→69%、重さ・外周の条件は変わらない）。半径を 36 に広げる案は、さらに効くが外周のはみ出し（先端 最大 約 6px）と、外周タップの 75% で寄せ上限（44）に当たる代償がある。半径 40 以上は、外周寄せ上限 44 のままでは皿の外へ大きく出る（17px 前後）ため、Y2（上限の引き上げ）が未承認の現状では現実的でない。
4. **半径・片数・欠片だけでは「1 タップ = 局所散布」の限界は超えられない**。タップ間隔が散布の直径より大きければ、塊に見えるのは構造的に避けられない。根本解消は #825（配置方法）か Y3（全体レイヤー）の領域で、どちらも未承認。

## 2. 方法（既存コードの出力の再集計。描画はしていない）

- **対象のタップ**: Owner の 3 か所 (50,30)(28,62)(72,62)。皿 300px 換算で、ペアの間隔は 116・116・132px。1 単位 = 1.5px（箱 96px = 64 単位）、散布の回転 −18° と外周寄せ 44 を含めて、実際の描画位置を計算。ピース id は 150 通りの組み合わせ（`topping-N`）。
- **「塊」を測る指標**（Owner の目の判断の代わりではない、**近似**）:
  - **橋の片数**: 2 つのタップの中点を中心とする半径 24px の円に入る、欠片以外（幅広・細長）の薄片の数。
  - **橋が架かる割合**: 上の円に薄片が 1 枚以上ある（タップのペア）の割合。
  - **最近傍比**: 他のタップのピースまでの最近傍距離 ÷ 同じタップのピースまでの最近傍距離。1 に近いほど「ひとつづきの散布」、大きいほど塊。**同じタップ内の密度が上がると分母が小さくなって比が大きくなる**ので、橋の指標と合わせて読む。
  - **空白円**: 3 つのタップが作る三角形の内側で、ピースに触れない最大の円の半径。
  - **重さ**: 1 散布のインク面積（長さ×幅×0.7 の合計、相対値）。
  - **外周**: 皿中心から 38〜48% のタップ 4 距離×12 方向×60 id で、寄せの上限に当たる割合と、先端（保守的な推定）が皿の外へ出る最大量。
  - **RESULT のリーチ**: 散布の届く範囲が RESULT の皿（196px、本番の縮尺 0.75 と仮定）の何 % か（配置時は 22.5%）。
  - **白い中心部のインク**: 皿の中心から 90px 以内のインクの割合（焼成後のモッツァレラの白い面の目安。**面積は画像から読んだ概算**）。
  - **CUT 3 本で切れる割合**: 中心を通る 3 本（0/60/120°）の切り線の近くに入るピースの割合（RESULT の縮尺）。
- **反事実の数値シミュレーション**: 半径・片数・欠片の数と割り当て・FADE を変えた場合の数値を出すため、rev.6 のレイアウト関数を**パラメータ化した計測用の複製**（スクラッチ。**リポジトリには入れていない・描画していない・画像を作っていない**）を使った。**rev.6 の設定にすると、20000 id の出力が本物のモジュールとビット単位で一致し、外周寄せの結果も一致する**（不一致 0）。rev.5 相当の基準（L0）の指標は、本物の rev.5 のコード（`0318d2b9`）の指標とほぼ同じ（橋の片数 0.56 対 0.53、橋が架かる割合 46% 対 44%、最近傍比 3.56 対 3.53）で、分離の信頼性の根拠になる。
- 指示の「既存測定の再集計のみ」に対し、**寄与の分離には反事実が必要なため、上の計測用の複製を使った**（未承認の描画変更・試験実装ではなく、数値のみ）。
