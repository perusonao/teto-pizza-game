## P1（Phase 2着手前に直したい・優先度高）

1. **トッピングの重なり配置に対する視覚的ガード無し**
   モッツァレラ／バジルは自由座標に配置されるため、同じ場所に連打すると具材が完全に重なり、見た目上「何個乗っているか」が分かりにくくなる（下記スクリーンショット参照）。個数はスコアに反映されるが、プレイヤー体験としては「ちゃんと自分でバランスよく配置した」達成感が薄まる。最低限、既存トッピングと近すぎる位置への配置を弾く／自動で少しずらす、のどちらかが望ましい。
2. **「取り出す！」を押し忘れた場合のフェイルセーフが無い**
   焼成ゲージは0↔100を往復し続けるだけで、上限時間や「焦げすぎ」の明示的なペナルティ演出が無い。理屈上は何秒待っても良し悪しはスコア計算のみで決まるため、「早く操作しなきゃ」という緊張感（＝ミニゲームとしての意味）がやや弱い。将来のPhase 2で「焦げ演出」を入れる前提であれば許容範囲。

## P2（軽微・任意）

1. **キャラクター画像の解像度不統一**: `teto.webp`は320×320だが`mito.webp`/`blue.webp`は160×160。表示は48×48円形なので実害はないが、将来ポートレートを拡大表示する演出（会話クローズアップ等）を追加する場合は再書き出しが必要。
2. **焼成ミニゲームの速度が固定**: `SPEED = 55%/秒`固定で、レシピごとの難易度差が無い。1レシピのみのPhase 1では問題ないが、Phase 2でレシピが増える際は速度もレシピデータに含めると良い。
3. **ソースの重ね塗りができない**: `APPLY_SAUCE`は常に配列を上書きするため、複数タップしても見た目は変わらない（悪影響はないが「反応が無い」ように見える可能性）。
4. **図鑑未発見時のサムネイルが「？？？」のみ**: シルエットなど視覚的な「気になる」演出があると、次回作を作りたくなる動機付けとしてより強くなる（Phase 2向け）。
5. **BAKEフェーズの残り時間・失敗条件の説明がゲーム内に無い**: 初見でも詰まりはしないが、「ちょうどいいタイミングで取り出そう」という teto のセリフだけが頼り。

## First Fun Pizza評価（重点項目ごと）

### 1. キャラクター
- `teto.webp` / `mito.webp` / `blue.webp` はいずれもイラスト調の犬キャラクターとして統一感のある絵柄（テト＝黒ポメラニアン＋ボウタイ、ミト＝白ポメラニアン＋リボン、ブルー＝ハスキー＋バンダナ）で、AI再生成の粗さや破綻は見られず、そのまま使われている。
- ただし表示サイズは会話ボックスのポートレートのみ（48×48円形）で、ゲーム画面本体にキャラクターが常駐しているわけではない。小さすぎて識別できない、ということはないが、「テトたちと一緒にピザを作っている」実感は会話パート以外では薄め。
- 誰が話しているかは、ポートレート＋名前ラベル＋（ブルーのみ）吹き出しの左右反転、という3重の手がかりがあり直感的。

### 2. ピザ作り
- 中央のピザ（`min(78vw, 300px)`）は常に画面内で最大の要素であり、主役として成立している。
- タップで具材を「置く」操作は、位置を選べる分「材料選択クイズ」よりは一段階楽しい。ただし配置精度や重なり制御が無いため、「丁寧に並べて作った」というクラフト感はまだ弱い（P1参照）。

### 3. UI
- 390×844で全フェーズが1画面に収まり、横・縦とも実機スクロールなしを確認（`scrollHeight === clientHeight === 844`を全フェーズで確認）。
- 「焼く！」ボタンは赤系グラデーション＋炎絵文字＋横幅強調（flex: 1.4）で他ボタンより明確に主張しており、迷わない。
- 情報量は3スコア＋星＋セリフ程度に抑えられており、スマホ画面でも窮屈さは無い。
- タッチターゲットは全ボタン・チップで44px以上を確保済み（実測値は上記参照）。

### 4. ゲーム性
- 初見でも、デフォルト選択とヒントセリフの連携により、説明文なしで最後まで迷わず進められることを確認。
- マルゲリータ1枚だけでも、「ソースを塗る→具を置く→焼き加減を狙う→評価される→図鑑に載る」という一連の小さな達成体験が成立しており、「もう一度作る」を押したくなる動機（星3を維持したい／レシピ図鑑を埋めたい）は最低限用意されている。
- 焼成ミニゲームは実際に操作の巧拙がスコアに反映される、意味のある操作になっている（適当に押すと焼き加減スコアが下がることをロジック上確認済み — `scoring.ts`のbakeScore計算）。
- 結果画面の星＋スコアバー演出は簡潔ながら達成感がある。

### 5. Visual
- 完成イメージへの完全一致は求めない前提で見ても、「あたたかい木目調＋トマトソースの赤＋焼き色」の配色は「美味しそうなピザ」「テトたちの世界観」に寄っており、方向性としては十分。
- 「触って作りたくなる画面」という観点では、ドロップインアニメーションやグロー演出などの小さなフィードバックが効いており、静的なフォームには見えない。
