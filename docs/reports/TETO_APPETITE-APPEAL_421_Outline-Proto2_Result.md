## 1. Owner 評価（第1試作）と原因
「広がり方は改善したが、白い楕円を何枚も重ねたように見える」。原因: ぼかし 0.8px・アルファ最大 0.62 の「輪郭のコピー」6 枚が、それぞれ縁を持つ別の楕円として見えた（内側の楕円縁、丸い張り出し、シート感）。外周の明るい画素は M1 の 0.14 に対し 0.62 と、白さも増えていた。

## 2. 第2試作の方式（box-shadow の使い方を見直し）
コピーを増やすのではなく、「縁を持つ層」をやめて**羽化した層の和**にした。
- **本体の縁**: 縁の不透明度を 0.94 → 0.72（`--bake-cheese-body-3`）に下げ、スカートが始まる強さに合わせる。中心は乳白色（240,235,223）で厚く、縁へ向かい少しクリーム色（235,226,207）に連続変化。
- **近い 4 層（スカート）**: ぼかし 1.6〜2.2px、アルファ ≤0.3、到達 1〜3.2px、広がり 0.3〜0.9px。向きはピースごとにずれる。重なりで厚→薄の勾配ができ、層ごとの縁は見えない。
- **遠い 2 層（薄い舌）**: ぼかし 2.4px、アルファ ≤0.24、到達 4.2〜6.8px、主に横方向。丸い張り出しではなく、薄い不規則さだけを足す。
- 色は焼成に追従（クリーム→金→茶）。決定的ハッシュによる個体差は維持（`Math.random` 不使用）。
- 変更ファイル: `src/logic/bakeVisual.ts`、`src/App.css`（コメントのみ。層数・構造は第1試作と同じ 6 層）、`src/logic/bakeVisual.test.ts`、`e2e/mozzarella-melt-421.spec.ts`（層ぼかしの上限）、撮影スペック（矩形 JSON 出力を追加）、本 docs / 画像。
- **変更していないもの**: 焦げ目（斑点）、アニメーション、採点・`classifyBake`、焼成時間、CUT、保存、経済、`PizzaStage.tsx`、DOM、生の見た目。
