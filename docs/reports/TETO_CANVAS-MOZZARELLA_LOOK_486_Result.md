# Canvas モッツァレラ 焼成後の見た目改善（#486 / PR #487）

Owner の iPhone 実機 HV（HEAD `48519d6`）: Canvas OFF は白い円盤で溶けて見えない。ON は不規則に広がり改善したが、白い塊が目立ち自然な溶融表現としては不十分。既定 ON 化は不承認。

## 変更（`src/logic/cheesePool.ts` の `renderWithGeometry` のみ。純関数・決定的）
全ての変更は 1 つの係数 `fx = smoothstep(0.3, 1, melt)` に掛かる。**melt ≤ 0.3 では `fx = 0` で、焼成前（melt 0）はバイト単位で従来と同一**（変更前後の出力を比較して確認）。

1. **中心の白い塊**: 中心色を chalk white から cream へ（`CREAM`）。低周波ノイズでまだらにして単色の白を避ける。中心は不透明のまま（最も厚い部分）。
2. **ソースとの境界**: 外周ほど半透明（`veil`）にしてソースを透かす。薄い斑点も追加。縁の外側にごく薄い暖色の油膜（`OIL`、最大 α≈0.17）。
3. **焼き色と艶**: 控えめな金色の bloom（toast に比例、外周ほど強い）。鏡面ハイライトを melt に応じて最大 1.7 倍。
4. **ぼかしだけに頼らない輪郭**: エッジのしきい値を細かいノイズで揺らし（半径の数 %）、縁が小さな出っ張りと欠けを持つ。ぼかし幅は広げていない。
5. **焼成前**: 不変（上記）。
6. **安全性**: `CheesePoolCanvas`（透明化検出・再描画・M1 フォールバック）は変更なし。

## テストの基準変更（意図的）
旧デザイン（不透明・chalk white）を固定していた数値基準を、新デザインに合わせて更新した（緩めた箇所と理由はコメントに記載）:
`edgeWidthPx` 7.5→11、`thin` 0.35→0.6（中央値 0.14→0.55、最大 0.25→0.65）、core 色 ~(238,234,218)→~(234,224,200)、warm の下限（full 0.15→0.05、toast 0.6 の中央値 0.08→0.03）。
新規テスト 3 件: 焼成前（melt ≤ 0.3）に半透明の被膜がないこと、中心は不透明で外周・斑点は透けること、油膜が melt 1 にのみ存在すること。
この緩和は「見た目を変える」という Owner の要求に由来する。**緩めた基準が自然さを保証するわけではない**（自然さは実機 HV でのみ判定する）。

# 追補: 描画構造の見直し（Owner HV `61b9a06` の結果を受けて）

Owner HV: ON の 3 か所は正常表示。ただし実物の焼き上がったモッツァレラと比べ、白いぼやけ・立体感不足・焼き色不足が残る。

## 構造上の原因（監査）
`61b9a06` は「不透明な平らな板」の上に透け・色・ぼかしを後から重ねていた。
1. **厚みが平ら**: 厚みは `1 - 0.2ρ²`（0.8〜1.0）で、ほぼ一定。法線は縁の 1 周でしか傾かず、中心は陰影のない一様な白になる（立体感不足）。
2. **透け・縁・色が厚みと無関係**: 外周の半透明（veil）、縁のゆらぎ、油膜が厚みと別々の係数で、縁の「ぼかし」と白い発光になった。
3. **縁が全周同じ性質**: 立っている縁と薄く流れた縁の区別がない。
4. **焼き色が縁と青い blister のみ**: 局所的な小さな焼き斑点が無い。

## 変更（`renderWithGeometry` のみ。`fx = smoothstep(0.3, 1, melt)` で混合）
1. **厚みを実プロファイルに**: 中心は plateau、外周で 0 へ落ちる厚み（低周波ノイズでわずかなうねり）。陰影は暖色の影（灰色にならない）で、薄縁には光沢を出さない。
2. **不透明度を厚みから導出**: 中心は不透明、外周ほど半透明（床 0.52）。薄い斑点でもソースが透ける。
3. **縁を方向ごとに変える**: 突出・舌（tongue）は薄く流れて柔らかく、湾入部は立って明瞭（縁の暗い lip も立っている側だけ）。縁の幅は 0.05〜0.16（ρ 単位）。一様なぼかしと油膜は廃止。
4. **色を厚みで決める**: 厚い所は乳白色、薄い所は暖かいクリーム（まだらなノイズつき）。焼成に応じて本体全体が少しクリームゴールドへ。
5. **小さな金色の焼き斑点**: 高周波ノイズの山を閾値で切り、薄い所を優先して局所的に（toast 比例）。
6. 焼成前（melt ≤ 0.3）は **元の `dc1d20b` の描画とバイト単位で同一**（18 パターンのハッシュ一致を確認。うち 7 件をテストに固定）。透明化検出・M1 フォールバック（`CheesePoolCanvas`）は不変。外周を 1.2 % 広げて、半透明化による見かけのサイズ減を補った。

## 検証
- Vitest（cheese 系 34 件）、`tsc -b`、Chromium e2e 6/6（390×844 / 360×800）。全体 Vitest・lint・build・WebKit CI・Codex は別途記録。
- 数値基準の緩和は前回記載分に加え、(a) 旧 `oil film` テストを構造テストに置換、(b) 「warm」指標が厚み由来のクリームを褐色と誤認しないよう `toast` に連動させた。**基準を通すために見た目を調整した箇所がある**（speckle 係数 0.5、本体の色づき 0.16）。
