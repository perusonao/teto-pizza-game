# Pilot D（PR #701）Visual HV 追加撮影 Result — 焼き過ぎサーモン / 重なり / WebKit

対象: PR #701、HEAD `3a2149c4d2c8e2f3e2b4fd098b9c779c0762721e`。PR #701 のコード、共有 Preview、本番、Firebase、既存セーブ、#468 は変更していない。Codex の再依頼もしていない。
**これは iPhone Safari 実機 HV ではない。** Chromium（Playwright、DPR 2）と、**WebKitGTK（apt の WebKit エンジン、Selenium の WebDriver）**の自動撮影である。Playwright 公式の WebKit はこの環境では取得できなかった（`cdn.playwright.dev` が環境のネットワーク許可外）ため、代替として WebKitGTK を使った。Safari の描画・フォント（Apple Color Emoji を含む）・iOS の挙動とは異なる。OS 絵文字は描かれない（`pieceVisual` あり）ため、絵文字の差は今回の対象外。

## 撮影方法
- ゲーム本体は HEAD のソースの dev server（`TETO_TEST_HOOKS=1`）。使い捨ての localStorage（既存の Preview セーブには触れない）。
- Chromium: 390×844 / 360×800。ライブの BAKE 画面は、clock を止めて針を狙った位置（通常 70、焼き過ぎ 92）へ進めて撮影。
- WebKitGTK: ウィンドウの最小幅が 447px のため、**390 / 360 の iframe（同一オリジン）で本物の CSS viewport 390×844 / 360×800** を作った。ポインタ操作は W3C actions の実マウス。bake は実時間なので、通常は針 66 で即取り出し（焼成後 = FINISH 画面と RESULT で比較）、焼き過ぎは針 90 で撮影してから取り出す（取り出し時の針は約 100 で、Chromium の 92 より少し焦げが強い）。
- 動画は HV 方針により commit していない（Chromium 28 本、390×844 / 360×800。WebKitGTK の動画は撮っていない）。

## 撮影できなかったもの・限界
- iPhone Safari 実機、Apple Color Emoji、Playwright 公式 WebKit（取得不可。上記の理由）。WebKitGTK は Safari と同じエンジンの系統だが、別のビルド・別の描画バックエンドである。
- ゲーム操作による完全な重なり（仕様上できない）。合成の重ねは参考（DOM を操作した）で、実際のゲーム状態ではない。
- WebKitGTK でのクリームチーズの合成重なり（S5 は Chromium のみ）、WebKitGTK の動画。
- WebKitGTK の針位置は、スクリーンショットの遅延（約 0.5 秒）のため、BAKE 画面の撮影時刻に幅がある（焼き過ぎ ≈90〜100、Chromium は 92 で固定）。ライブ BAKE 画面の生地の色は Chromium と厳密には比較できない。FINISH / RESULT（静止状態）は比較に使える。
