# Issue #421 S2-A — 性能改善（前計算の最適化・余白・焼き色）Result

- ブランチ: `claude/issue-421-s1-cheese-pool`（S1b `7de0d83` の上）。**S2-A のみ**。S2-B・S2-C へは進んでいません。ゲーム画面への配線、PR 作成・Ready 化・merge・deploy・共有 Preview 切替はしていません。PR #468 は HOLD のまま。
- 計測は同一マシン・同一 Node 内で、S1b（`7de0d83` の worktree）と S2-A を交互に実行（S1b 3 回、S2-A は結果が同じ版の 1 回の 400 シード × 3 ラウンド。JIT 暖機のため最初のラウンドは除外）。時間は **Node（デスクトップ級）の中央値 / p95**。モバイルは 3〜6 倍を見込む必要があります。

## 1. 変更点
| 項目 | 内容 |
|---|---|
| 棄却サンプリング（最優先） | ①縦横比（最多の棄却理由）を 4 ビンおきの粗い評価で先に判定し、帯から 0.04 以上外れる候補は輪郭を作らずに捨てる（乱数列の消費は S1b と同一）。②三角関数表（cos kθ / sin kθ）で候補ごとの三角関数を無くす。③凸包を「ソート + monotone chain」から「角度順のまま Graham 走査」へ（星形なのでソート不要）。④`Math.pow(x, 1.5)` と `Math.hypot` をピクセル／ビン単位の内側ループから除去（`x*sqrt(x)`、`sqrt(x²+y²)`）。⑤ガウス項は e>40 で 0（exp(−40)=4e-18 で float32 表より遥かに小さい） |
| 輪郭の同一性 | **400 シードすべてで S1b と同じ輪郭**（型・縦横比とも一致。指紋 `b5d4610c` をテストに固定）。つまり画質は輪郭に関して変わりません |
| 64×64 | `CHEESE_POOL_GRID_CANDIDATE = 64`（暫定の既定候補）。`renderCheesePool` の既定は 96 のまま（黙って変わらない）。96 も維持 |
| 焼き色 | ブリスターの合計面積を「ピースの面積の 2%」で頭打ち（超える場合だけ全体を縮小）。基準サイズを 2.3 → 2.0。形・数・配置の乱数は従来通りで、**不規則さは保持** |
| 余白 | 枠取りを「完成輪郭（リップル込み）× 1.085（縁のぼかし 1.045 と溶け中盤のオーバーシュート分）」に変更。**画面端まで 3px（64×64）／4.5px（96×96）以上**（`CHEESE_POOL_MARGIN = 3/32` の比率）。S1b は輪郭にリップルを含めずに枠取りしていたため、最小 2px まで寄る例があった |
| 契約 | 決定性、LRU（幾何 48／画像メモ 64）、量子化メモ（grid 込み）、reduced-motion（オーバーシュート省略）、完成形（melt 1）が reduced-motion でも同一、は変更なし |

## 2. 性能（同一環境・同一 400 シード、S1b → S2-A）
| 項目 | S1b | S2-A | 比 |
|---|---|---|---|
| **幾何の前計算 p50** | 2.35 ms | **1.17 ms** | 0.50× |
| **幾何の前計算 p95** | 6.83 ms | **3.33 ms** | 0.49× |
| 幾何の前計算 p99 | 10.1 ms | 5.5 ms | 0.54× |
| 描画 96×96 p50 / p95（melt 1・toast 0.6） | 1.04 / 1.54 ms | 0.82 / 1.18 ms | 0.79× / 0.77× |
| 描画 64×64 p50 / p95（melt 1・toast 0.6） | 0.42 / 0.62 ms | 0.34 / 0.53 ms | 0.81× / 0.84× |
| 描画 96×96 p50 / p95（melt 0.5） | 0.85 / 1.29 ms | 0.68 / 1.01 ms | 0.80× / 0.78× |
| 描画 64×64 p50 / p95（melt 0.5） | 0.34 / 0.51 ms | 0.28 / 0.45 ms | 0.83× / 0.88× |
| **初回（幾何 + 最初の描画）64×64 p50 / p95** | 2.3 / 6.4 ms | **1.2 / 3.1 ms** | 0.52× / 0.49× |

- 輪郭選択（棄却サンプリング）の平均は 1.8 → 0.6 ms（候補数は変わらず、中央値 10 回。縦横比で捨てる候補は輪郭を作らない）。
- 前計算の残りは約 0.6 ms（96）／0.3 ms（64）で、ほぼピクセルごとの `atan2` とノイズ地図です。
- モバイルでの初回（64×64）は 3〜6 倍を見込むと **p50 で 4〜7 ms、p95 で 9〜19 ms** 程度（S1b は 7〜14 ms／19〜38 ms）。**実機での確認は S2-B 以降の配線後にしか出来ません。**

- 凸性は S1b と同じ（輪郭が同一のため）。**写真の 0.76〜0.84 には届いていません（S1b と同様、折り紙状を避けるため意図的）。**
- 焼き色は「頭打ち」のため、写真の範囲（1〜4%）に入るシードが約半数から 83% へ、5% 超が 28% から 0.5% に。中央値は 3.7% → 2.8%、最大 11.6% → 5.1%。p5 は 0.8%（ほぼ焼き色なしのシードも残る＝個体差は維持）。
- 等価直径が約 5% 小さくなったのは余白の設計による（S1b はリップル分がはみ出し、最小 2px まで寄っていた）。S2 で CSS px に拡大する前提なので、見た目の大きさは `CHEESE_POOL_SPAN_PX` 側で調整できます。

### 余白の確認
- 全 400 シードの melt 1 だけでなく、**150 シード × 25 段階の melt × reduced-motion 有無**で、見える画素（alpha>0）の最小余白を測定: 64×64 で最小 3px、96×96 で最小 5px（枠の係数 1.085 を決める前の試行で、係数が小さいと 64×64 の溶け中盤で 2px まで寄ることを確認）。単体テストは 60 シード × 9 段階 × reduced-motion 有無 × 両グリッドで、64 は ≥3px、96 は ≥4px を検証。

## 4. 画質（64×64 と 96×96、同じ輪郭）
- 64 を 96 へ拡大して比較（200 シード）: RGB の RMSE 中央値 1.7 / p95 2.3 / 最大 2.5、輪郭の差は面積の約 0.5%（S1b と同等）。凸性は 64 が約 0.009 低い。
- 目視（`s2a-96-vs-64-baked.png`、`s2a-96-vs-64-melt.png`）では、輪郭・陰影・色は識別できず、焼き斑の小さな衛星が 1〜2 個崩れる程度です。

## 5. 見た目の確認（性能改善による画質悪化が無いこと）
- `s1b-vs-s2a-baked.png`、`s1b-vs-s2a-baked-2.png`、`s1b-vs-s2a-melt.png`: 輪郭は同一。焼き斑は小さくなり、不規則な形（楕円・衛星・濃い縁）は保たれています。白い球状・均一な点状になった例は見当たりません。
- `s1b-vs-s2a-warm-outliers.png`: S1b で焼き色が最大だった 6 シードの前後。大きな斑が適度な大きさになりました。
- `s1b-vs-s2a-margin-melt085.png`: S1b で端に寄っていたシード（melt 0.85）の前後。S2-A は輪郭が切れず余白があります。
- 残る見た目の課題（S1b から変わらず）: 舌の先の薄いピンクの残り、凸性が写真より高い。S2-A では触っていません。

## 6. 検証
- `tsc -b`、`oxlint`、`vitest` 全件、`npm run build` が成功（結果は Issue コメントに記載）。
