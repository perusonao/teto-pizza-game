## 3. 原因別の分析

### 3.1 課題 ②「大きく厚く見える削り片」（形状・大きさ）

**インクの内訳（V8-1、1 散布、4000 id）**: フレーク 5.65 片＝**インクの 76%**、細長 1.37 片＝13%、欠片 4.49 片＝12%（合計 592、相対値）。**課題の主役はフレーク**で、欠片ではない（→ V7-A は効かない）。

| 手がかり | 現在の描画（`ParmigianoShavings.tsx`） | 見え方への効き方（推定） |
|---|---|---|
| **大きさ** | フレークの長さ 10.5〜17 単位（実機で約 16〜25px）、幅は長さの 38〜80%（平均 59%） | モッツァレラの玉と同程度の「板」。実物の薄い削り片は軽く小さく散る印象 |
| **不透明度** | 塗りの不透明度 0.8（トマトソースがほぼ透けない） | 「薄く透ける」感じが出ない＝厚く見える |
| **輪郭** | 暖色の縁取り（不透明度 0.22〜0.52、幅 0.14〜0.30 単位） | 3 倍密度の実機では細い縁取りが見え、**板の縁**に読める |
| **影** | 接地影（不透明度 0.05〜0.12、下に 0.9 単位ずらす） | 浮いた厚みの手がかり |
| **内部の描き込み** | フレークに**明るい芯**（不透明度 0.16）と**木目線**（不透明度 0.4） | 「層のある塊」「木片・アーモンドスライス」に見える |
| **輪郭の形** | 9 角形を 0.3 面取り | 角の丸い**チップ状**（紙のように薄く波打つ形ではない） |

→ **「厚く見える」のは、輪郭・影・芯・木目という“厚みの手がかり”が重なっているため**（推定。実機での単独の効果は未検証）。**サイズ（②の「大きい」）と質感（②の「厚い」）は別の要因**で、単独に試験できる。

### 3.2 課題 ①③「まとまり」と「散布密度の偏り」（分布）

**Owner のタップ位置の推定**: 実機の分布（内側 23／中間 10／外側 1）に、V8-1 のレイアウトで 3 タップ（中心から距離 ρ、角度は無作為）を 300〜400 通り試して最も近いのは **ρ ≒ 14%（皿幅 290px で約 40px）**（シミュレーション 24.3／8.8／1.5、外側 2 以下になる確率 79%）。ρ = 20% では 18.5／11.4／4.1（外側 2 以下は 22%）、ρ = 26% 以上では外側が 5 以上。**（タップ位置は画像から推定した仮定で、確定ではない。）**

**中央寄りの 3 タップ（ρ ≒ 14%）での各案の数値**（300 通り、皿幅 290px）:

| **V8-1（現在の #875 head）** | 24.2／9.0／1.4 | **4%** | **65%** | 0.57 | 587 |

**Owner の前の 3 か所（ρ ≒ 25%）では**: V8-1 は 16.1／12.2／5.6（外側 16%、被覆 65%）。半径 42 で外側 14%・被覆 73%。

→ **読み取り**:
1. **中央寄りに置くと、V8-1 でも rev.6 と同じ偏り**（外側 4〜5%）。V8-1 の効果（橋が架かるペア +17.6pt）は、**タップが離れている場合**の話で、**中央に集まったタップには効かない**。
2. **半径・片数・欠片数は、中央タップの偏りに効かない**。半径 46 でも外側 11%・被覆 76%。**片数を増やすと中心がさらに重くなる**（内側 31）。**欠片 2〜3 は重さ +21%で偏りは同じ**。
3. 外周寄せ 44 は**外周のタップにしか効かない**。中央タップの課題は、**外周の制約ではなく、「固定半径の局所散布が重なる」性質**から来る。
4. **構造的な限界**: 近傍のタップ・既にある散布を見ない限り、重なった場所は濃く、ない場所は空く。描画だけの調整では、被覆を 65%→76%（半径 46）に上げるのが上限で、そこへ行くには外周の制約（先端が皿の外へ最大 約 25px）を破る。

## 6. 推奨・リスク・往復数

**推奨する次の単独試験（順）**:
