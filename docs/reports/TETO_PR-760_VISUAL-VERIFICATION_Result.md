## 1. 方法

- PR head と main をそれぞれ別の worktree に置き、ローカルの Vite dev server（`TETO_TEST_HOOKS=1`）に対して、同じ Playwright シナリオを実行した。
  - Chromium は `/opt/pw-browsers/chromium`、deviceScaleFactor 2。
  - viewport は 390×844 と 360×800。
- シナリオのスクリプトは scratch に置き、コミットしていない。PR #760 の `e2e/issue-733-icons.spec.ts` と `e2e/cooking-prep.spec.ts` の操作手順を流用している。
  1. 並べたピザ: 図鑑から研究（？？？ピザ A（牛肉））→ 生地 → ソースなし → モッツァレラ 2 → 具材。
     - 肉系・野菜系の絞り込みを使い、牛肉・ベーコン・ハム・ピーマン・青ねぎ・ズッキーニを 1 個ずつ置いてから焼成した。
  2. 下ごしらえ「炒める」: `?cookPrep=on`（Preview/DEV 限定。本番では OFF）で牛肉を 3 個置き、フライパン画面を開いた。
     - 時計を止めて 0.1 s / 1.9 s / 3.0 s / 3.9 s で撮り、best で取り出して、生地上の炒め済みの状態まで撮った。
- 各段階で `scrollWidth ≤ innerWidth`、`scrollHeight ≤ innerHeight` と、具材の重なり・はみ出し・画面外を DOM から計測した。

## 3. 改善案（任意。V3/V4 の要確認に対して）

1. **炒め済みの色を少し明るく、暖かくする**（`src/logic/prep/beefDoneness.ts` の cooked 目標色）。例:
   - 外側 `#5f331f` → `#6e3c22`
   - 輪郭 `#2e1a10` → `#3a2114`
   - 断面 `#7a4226` → `#8a4e2c`

   20px 台でも「焼けた肉の茶」に見えるようにする。単調性テスト（全部位が生より暗い）は満たしたままにできる。
2. **芯を断面より暗くするか、断面と同じ色にする**（例: `#9a5a3c` → `#7f4628`）。今は明るい芯がハイライトに見え、「中まで火が通った」より「ツヤ」に読める。
3. （PR #760 の範囲外。既存の問題）結果チップでピーマンが文字に重なる件。`.ingredient-glyph--green-pepper-strips` に、インライン文脈でだけ `margin-inline-end: 0` を当てるか、チップに `gap` を入れる。別 Issue が妥当。
4. V2 の要確認で実機に混同があった場合: ピーマンの輪の中に小さい種の点（1〜2 個）を足すか、ふくらみを強くして、青ねぎの丸い輪との差を大きくする。
