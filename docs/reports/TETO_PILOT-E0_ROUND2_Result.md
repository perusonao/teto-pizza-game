## 5. 食材ごとの所見

### 5.1 ピーマン GP-A2（20〜32px で青ねぎ・ハラペーニョと識別できるか）
- **形**: 3 本の平行な弧 vs 青ねぎ（小さな輪の房）vs ハラペーニョ（緑の四角）。32 / 28px は明瞭。24px はやや細く、**20px は「緑の縞」**まで（それでも輪の房・四角とは別物）。
- **色**: 緑同士で近い（青ねぎ ΔE 14.7、ハラペーニョ 14.0、大葉 7.0、パクチー 3.1）。**色では区別できず、形に頼る**。グレースケールでも 3 本線は他と別形。
- **実画面（`pe0-05`）**: ピザ上の同じ縮尺で、青ねぎ・ハラペーニョと並べて区別できる。焼成後の色調でも緑のまま保たれる。
- 注意: 形の重なり率は GP-A2↔大葉 0.66、↔青ねぎ 0.65 と中程度（指標は塊感に偏る）。

### 5.2 パプリカ BP-B2（ピザ上で大きすぎないか・ピーマンと並べて）
- ピザ上は 1.65em で GP-A2 と釣り合う（初稿 BP-B は箱の約 75% を占め、大きかった）。**縮小後は 20〜24px で小さな赤い点になる**ため、小サイズでの読みやすさは初稿が上。補正値の確定が条件。
- ピーマンとの識別: 色差 ΔE 71、形は丸い実 vs 細切りで別。**並べて混同しない**（`pe0-05`、`pe0-07`）。
- 注意: ペパロニ（赤い丸）とは色が近い（ΔE 16、形 0.62）。トマト（`tomato-slice`）との比較は未実施。

### 5.3 パイナップル PA-A2（フェタなどの角切りとの比較）
- フェタ（白い角切り）とは形 0.26 / 色 62 で**明確に別**。コーン（黄の絵文字）とは形 0.33 / ΔE 13（色は近いが形が別）。最近傍はフォンティーナ（形 0.42 / ΔE 14、黄の扇形）で、外皮の濃い帯の有無で区別。
- **外皮の主張**: v1 より帯が細く淡く、果肉の黄色が主役になった。トレイ chip・ピザ上とも自然。
- **弱点**: 現行 🍍（葉つきの丸ごとの果実）より、離れて見たときに「パイナップル」と分かりにくい（`pe0-06` の等倍）。

### 5.4 チキン（承認の維持と、骨なし候補の比較）
- **承認済みドラムスティックは変更していない。** 実画面でも、ピザ上・焼成後・RESULT で自然に読める（`pe0-01`）。
- B1（ひと口）: じゃがいもに近い（形 0.64 / ΔE 22）→ 前回所見を維持（リスク高）。B2（グリル細切り）: 縞で区別できるが、指標上の最近傍はじゃがいも（§2）。
- 骨なし化を進める場合: B1 は橙寄りの色・断面を大きく・個数を減らす、B2 は焼き目の向きと色の調整（**Owner の指示後**）。

### 5.5 焼成後の見え方（参考。E-4 は保留のまま）
- 焼成後も、具材は色調がわずかに変わるだけで形は変わらない（現行の絵文字も候補 SVG も同じ）。チーズが具材の上に溶け広がる表現はない。これは #421 / #468 の課題で、**本 Pilot の対象外（保留）**。

**契約（Anti-Oracle 2.1）との整合**:
1. **INV-D7（直接の「なし」を出さない）**: N-A は禁止語を含まず、**文字列としては適合**。ただし契約の文言は「『ソースなし』『ソース不要』に**相当する表現**を置かない」。N-A は対象のレシピや組成について述べず、「進んでよい」という一般的な許可だが、**「ソースを使わない選択肢の明示」という意味では趣旨に触れうる**。→ **Owner が解釈を決める**。
2. **INV-D4（target 非依存）**: 全レシピで同一文言・同一 DOM にすれば適合。**図鑑・技法の発見状況・Hint・Research の進行で出し分けない**こと（技法を発見した後に消す等は漏洩になる）。出す場面は Free Cooking / Research（モードはプレイヤーの選択でレシピに依存しない）。
3. **既存ガードの範囲**: 既存の走査は、行・Notebook・保存された facts・Research エントリ・Hint 5.0 ビューなどが対象で、SAUCE 工程の画面テキストは走査対象外。したがって N-A が既存テストを壊すことはないが、**契約の趣旨を守る追加テストが必要**（全 target で DOM 同一、禁止語なし、aria・Notebook・保存に出ない）。
4. **正解を明かさないか**: 案内は「塗らなくても進める」という操作の許可だけで、どのレシピがソースを使わないか、ソースが何かには触れない。「次へ」は現状でも押せるため、**新しい情報を与えるのは『ソースを使わない選択が許される』というメタ情報のみ**。技法の謎かけ（Dex の「調理法」）が既にこの存在を示唆しているため、追加の漏洩は小さい。
5. **より中立な案（N-D）**: SAUCE だけでなく**全工程共通**の案内にすると、ソース固有のメタ情報が消える（チーズ工程を持たないレシピもあるため、事実としても正しい）。UI の変更範囲は広がる。
- 実装は行っていない。実装時は上の項目 3 の追加テストと既存の契約テスト（`researchResultRows`、`gameReducer.techniques.privacy`、`deductionProduction.gate`、`hint5Production.gate`）を実行する。#489 と置き場所を調整。
