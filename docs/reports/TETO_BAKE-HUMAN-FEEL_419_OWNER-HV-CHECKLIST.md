## A. 一方向進行（✅）

- [ ] 「焼く！」後、針が左端から右へ進み、**一度も左へ戻らない**
- [ ] 針が右端（100）に着いたら**右端で止まり、戻らない**
- [ ] 焼き色（生地・チーズ・焦げ・煙）が**最後まで逆戻りしない**（途中で一度も薄くならない）
- [ ] 右端で**焦げ状態のまま保持**され、勝手に取り出されない／失敗にならない
- [ ] 「取り出す！」を押すまで BAKE が続き、押すと RESULT に進む

## B. 目安ゾーン（✅ OD-419）

- [ ] 0〜3 秒: 目安ゾーン（生／ちょうどいい／焦げの色帯）が見える
- [ ] 3〜5 秒: ゾーンだけがなだらかに薄くなる
- [ ] 5 秒以降: ゾーンが完全に消え、**復活しない**（10 秒まで確認）
- [ ] **針とゲージ本体（トラック）は消えない**（常に見える）
- [ ] フェードのタイミングがレシピによって変わらない（2 レシピ以上で確認）
- [ ] 通常ピザ作りの CUT のガイド（角度ガイドの表示とフェード）が**変わっていない**（✅ O6）

## C. 答えの漏れ（✅ O8 / 🧪 P3 P6 P7）

- [ ] 「取り出す！」ボタンが**正解位置で光らない**（ゾーン内・外・消失後のどこでも）
- [ ] 針の色が位置で変わらない（ゾーン消失後に色で答えが分からない）
- [ ] Teto のキャプションが、ゾーン消失後に「今がチャンス」等の状態を明かさない
- [ ] ピザの見た目だけで「そろそろ」が判断できる（判断しにくければ記録: ＿＿＿＿）

## D. 誤確定防止（🧪 P4）

- [ ] 「焼く！」を素早く連打／ダブルタップしても、**即 RESULT にならない**
- [ ] 開始後 0.3 秒ほどで「取り出す！」が押せるようになる（待たされ感が気にならない）
- [ ] 「取り出す！」の連打で**二重に確定しない**（RESULT・図鑑登録・Pitz が 1 回分）

## E. 背景復帰（✅ O11 / 🧪 P5）

- [ ] BAKE 中にホームへ戻る／アプリ切替 → 30 秒以上待って復帰しても、針が**飛ばない**（いきなり右端・焦げになっていない）
- [ ] 復帰後、ゾーンのフェードや入力ロックが「裏で進んでいた」状態になっていない
- [ ] 画面ロック→復帰でも同様

## F. Lunch Rush 180 秒（🧪 P1 P2）

- [ ] Rush でも BAKE が 10 秒の一方向で、ゾーン／針／終端の挙動が通常と同じ
- [ ] Rush のクロックが BAKE 中も減っている／背景中も減る
- [ ] 180 秒で何皿作れたか: 変更前 ＿ 皿 / 変更後 ＿ 皿
- [ ] 待たされ感（target 手前の約 4.5〜6.5 秒）: 気にならない / 長い / 短くしたい（→ 希望秒数 ＿＿）
- [ ] Rush の BAKE 中にタイムアップしたときの挙動が従来どおり
- [ ] 判断: **Keep（10 秒共通）/ Adjust（秒数変更）/ Split（Rush 別速度＝別 Issue）**
